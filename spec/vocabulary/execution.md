# The words of execution

## Terms

- **review** (noun) → object review. A reviewer's reading of commits against the spec and the repository's rules, written as graded findings: a pull request review or an architecture review.
- **batch plan** (noun) → object batch plan. The file `.shop/batches/<n>/plan.md`, with a batch's tasks and their statuses.
- **batch brief** (noun) → object batch brief. The brief `work batch start` writes for the one fresh agent that runs the batch: the batch, its tasks and worktrees, the skill it follows, the rules and the lessons, and where it stops.
- **review folder** (noun) → object review folder. The scratch directory `batch-<n>-review-<k>` under the batch's worktrees directory, which `work batch brief` writes a review's brief and change into and where the review's findings are saved, and which is never committed.
- **grade** (attribute) → attribute review finding.grade. 
- **Critical** (adjective) → value review finding.grade Critical.
- **Important** (adjective) → value review finding.grade Important.
- **Minor** (adjective) → value review finding.grade Minor.
- **building** (adjective) → value batch.status building.
- **in-review** (adjective) → value batch.status in-review.
- **awaiting-merge** (adjective) → value batch.status awaiting-merge.
- **merged** (adjective) → value batch.status merged.
- **abandoned** (adjective) → value batch.status abandoned.
- **pending** (adjective) → value task.status pending.
- **running** (adjective) → value task.status running.
- **done** (adjective) → value task.status done.
- **failed** (adjective) → value task.status failed.
- **triage** (attribute) → attribute review finding.triage. What a review asks of its finding: fixed on the branch before the merge, kept as an observation, or dropped.
- **fix now** (noun) → value review finding.triage fix now.
- **drop** (noun) → value review finding.triage drop.
- **touch** (verb, state) → relation kept change.touches. A commit's change adds, removes or alters a file. Forms: touches, touched. Frame: <kept change> touches <file>.
- **open** (verb, action) → operation batches.open. Forms: opens, opened. Frame: <actor> opens <batch>.
- **resume** (verb, action) → operation batches.resume. Forms: resumes, resumed. Frame: <actor> resumes <batch>.
- **finish** (verb, action) → operation batches.finish. Forms: finishes, finished. Frame: <actor> finishes <task>.
- **park** (verb, action) → operation batches.park. Forms: parks, parked. Frame: <actor> parks <item>.
- **submit** (verb, action) → operation batches.submit. Forms: submits, submitted. Frame: <actor> submits <batch>.
- **merge** (verb, action) → operation batches.merge. Forms: merges, merged. Frame: <actor> merges <proposed change>.
- **abandon** (verb, action) → operation batches.abandon. Forms: abandons, abandoned. Frame: <actor> abandons <batch>.
- **monitor** (verb, action) → operation batches.monitor. Forms: monitors, monitored. Frame: <actor> monitors <batch>.
- **review** (verb, action) → operation reviews.review. Forms: reviews, reviewed. Frame: <actor> reviews <thing>.
- **conclude** (verb, action) → operation reviews.conclude. Forms: concludes, concluded. Frame: <actor> concludes <review>.
- **the batches service** (proper noun) → service batches.
- **the reviews service** (proper noun) → service reviews.
- **the capability form** (proper noun) → object capability form. A capability file as 0.38 keeps it: its frontmatter names its `area:` and what it `specifies:`, and it holds no empty section.
- **the index form** (proper noun) → object index form. `spec/index.md` as 0.38 keeps it: one `## Composition` section, whose table `| area | kind | capabilities |` has a row for each area, naming its capabilities.
- **virtual environment** (noun) → object virtual environment. The directory `.venv` at the top of a workspace, whose `bin/python` runs the tests of a task and of a batch in place of the `python3` on `PATH`.
- **amend** (verb, action) → operation batches.amend. An item's lines laid again on the workspaces of its batch and of its task after they changed. Forms: amends, amended. Frame: <actor> amends <item>.
- **configure** (verb, action) → operation batches.configure. Forms: configures, configured. Frame: <actor> configures <setting>.
- **setting** (noun) → object setting. One key of `.shop/delivery.toml` that the plugin reads, under the table it belongs to, as `batch_size` or `[review] checks`. Plural: settings.
- **setting value** (noun) → object setting value. The value a setting is given, of the type the plugin reads it as, as `7` for `batch_size`. Plural: setting values.
- **settings file** (noun) → object settings file. The file `.shop/delivery.toml` of a bounded context, which holds its settings. Plural: settings files.
- **the delivery settings form** (proper noun) → object delivery settings form. The settings the plugin reads in `.shop/delivery.toml`: each key under its own table and its value of its own type.
- **conflict** (verb, state) → relation kept change.conflicts with. A task's kept change alters a part of a file, other than a capability's `unbuilt:` line, that a kept change of an earlier task in the batch alters otherwise, so that merging the task branches in task order, each after the ones before, with git's recorded resolutions, leaves the part unsettled. Forms: conflicts, conflicted. Frame: <kept change> conflicts with <kept change>.
- **base merge** (noun) → object base merge. A kept change on a batch's branch that merges the branch the batch started from into it, made after the batch's last review. Plural: base merges.
- **batch rule** (noun) → object batch rule. A rule of a bounded context's own setup that every agent running a batch follows, kept as one entry of the setting `[batch] rules` of `.shop/delivery.toml` and never in the plugin's code. Plural: batch rules.
- **reopen** (verb, action) → operation batches.reopen. A batch that awaits its merge taken back to building with a finding the person wrote on its proposed change, kept as a review. Forms: reopens, reopened. Frame: <actor> reopens <batch>.
- **batch summary** (noun) → object batch summary. What a batch cost and how long it took: its cost in dollars, its output, new input and cache-read tokens, its wall time, its opening time, its building time, the durations of its test runs and its review time.
- **batch summary form** (noun) → object batch summary form. The form a batch summary takes, which the batch brief gives the batch's driver to reply with: each figure of a batch summary under its name.
- **restate** (verb, state) → relation model line.restates. A model line declares an element that the domain model declares already, under the same name, with the members the element is to have in place of its own. Forms: restates, restated. Frame: <model line> restates <element>.
- **the review limit** (proper noun) → object review limit. The number of changed lines a pull request review reads in one batch's change, 1000.
- **review finding** (noun) → object review finding. One graded finding of a review.
- **workspace** (noun) → object workspace. A working tree `work batch start` makes for one task of a batch, in which the dispatch that builds the task works.
- **kept change** (noun) → object kept change. One git commit on a branch, with its message and its change. This: the commit the command makes.
- **batch** (noun) → object batch. Ready items built together on one branch and closed by its pull request, named `batch-<n>`, kept as the directory `.shop/batches/<n>/`. Plural: batches.
- **task** (noun) → object task. One unit of a batch plan, built in its own worktree.
- **proposed change** (noun) → object proposed change. The GitHub pull request of a batch's branch.
- **`pr-reviewer`** (proper noun) → object pr-reviewer. The agent that reviews a batch's pull request.
- **status** (attribute) → attribute batch.status. 
- **status** (attribute) → attribute task.status. 
- **observation** (noun) → value review finding.triage observation.
- **shared workspace** (noun) → object shared workspace. The workspace a workspace is shared to, in the shared store.
- **cite** (verb, state) → relation kept change.cites. A thing names another as what it stands on. Forms: cites, cited. Frame: <kept change> cites <item>. Frame: <proposed change> cites <item>. Frame: <quote> cites <message>. Frame: <thing> cites <observation>.
- **amendment** (noun) → object amendment. A kept change that work batch amend makes on the workspace of a batch or of its task, laying an amended item's requirements again. Plural: amendments.
- **the shop service** (proper noun) → service shop.
- **entrust** (verb, action) → operation shop.keep. The person gives a bounded context to the shop to keep under its id, beside the bounded contexts the shop keeps already. Forms: entrusts, entrusted. Frame: <actor> entrusts <bounded context>.
- **list** (verb, action) → operation shop.list. The person asks which bounded contexts a shop keeps. Forms: lists, listed. Frame: <actor> lists <shop>.
- **the driver** (proper noun) → actor the driver. Whatever runs a batch by asking the batches service for its next step and reporting each step's result back: an agent, a script or a runner.
- **poll** (verb, action) → operation batches.poll. The driver asks the batches service for the next step of a batch. Forms: polls, polled. Frame: <actor> polls <batch>.
- **findings file** (noun) → object findings file. The file `findings.md` in a review folder where the reviewer's reply is saved, which `work batch reviewed` reads. Plural: findings files.
- **batch step** (noun) → object batch step. What a batch needs done next, as the batches service says it to the driver: its instruction and the task, brief, review folder, findings file or finding it is about.
- **instruction** (attribute) → attribute batch step.instruction. What a batch step asks the driver to do.
- **prepare task** (noun) → value batch step.instruction prepare task.
- **build task** (noun) → value batch step.instruction build task.
- **finish task** (noun) → value batch step.instruction finish task.
- **submit batch** (noun) → value batch step.instruction submit batch.
- **review change** (noun) → value batch step.instruction review change.
- **fix finding** (noun) → value batch step.instruction fix finding.
- **fix task** (noun) → value batch step.instruction fix task.
- **park item** (noun) → value batch step.instruction park item.
- **stop** (noun) → value batch step.instruction stop.
- **shop** (noun) → object shop. The unit one product's work is managed and executed in, which keeps bounded contexts, each under its id. Plural: shops. This: the shop the request is made in.
- **look at failure** (noun) → value batch step.instruction look at failure. A batch step that asks the driver to look at the scenarios that broke a submit when they are of no task's item, with no task to fix named.
- **fix** (noun) → object fix. A kept change on the branch of a task of a building batch, made after the batch's last submit that a scenario broke, which the next submit tests. Plural: fixes.
- **abandon batch** (noun) → value batch step.instruction abandon batch. A batch step that asks the driver to abandon a batch that is still building when every item it held is parked, so no item is left to build.
- **feature generator** (noun) → object feature generator. The plugin's code that writes a capability's feature from its requirement groups, as a workspace holds it: a batch's workspace may hold a newer one than the checkout a command runs in.
- **the corpus form** (proper noun) → object corpus form. A corpus file's layout: its heading, then one block a requirement in id order, each block separated from the next by one blank line and the last ending the file with no blank line after it.
- **responsiveness** (attribute) → attribute feature generator.responsiveness. Whether a run of the feature generator ends within its time limit.
- **responsive** (adjective) → value feature generator.responsiveness responsive.
- **unresponsive** (adjective) → value feature generator.responsiveness unresponsive. A run of it does not end within its time limit or cannot be started.
