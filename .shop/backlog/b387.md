# A new capability on an item takes model lines and vocabulary entries, in an area it names

## Notes

UX trial 2026-11-19 (a checklists CLI bootstrapped from an empty repository at 0.39.0): after `work line b1 --capability checklists ...`, `work line b1 --into checklists --model|--term|--relation ...` each refused `there is no codified capability checklists in spec/capabilities/`, though docs/recipes.md 'Start a new capability' says they go through the same item; `--capability` writes no `area:` (nor `specifies:`) for them to go to. Every fresh context's first item hits this; the work-around was hand-writing spec/model/ and spec/vocabulary/.
