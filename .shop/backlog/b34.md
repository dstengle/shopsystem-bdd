# A batch-implementer agent type for a batch's tasks

## Notes

The plugin ships no implementer agent, so building-a-batch dispatches each task to a general-purpose subagent with its rules in the brief. A batch-implementer agent (agents/batch-implementer.md) would fix its tools, model and rules (red first, one scenario at a time, never edit a .feature, the Item: trailer, nothing under .shop/backlog/ or .shop/batches/, reply with what it built or one question) in its definition, as pr-reviewer does for the review; building-a-batch step 4 then names it. Raised by the person's question in quote-1, during batch-1.
