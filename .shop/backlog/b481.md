# work decision --amend with ids it names already completes, not git's nothing to commit

## Notes

work decision --amend <d> --enforced-by <id> (or --rests-on <id>) naming an id the decision names already leaves the text unchanged, so decision_amend.amend's shop_files.committed fails with git's nothing to commit; the amendment is to complete and change nothing (check the text unchanged before committing). Wave of the missing-command research, the person's words in quote-68.
