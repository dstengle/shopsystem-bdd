# migrate init takes --purpose and writes it under the index's ## Purpose

## Requirements

### upgrades

#### [g41] Founding a bounded context with a context purpose writes it in the index file
- [r41] While this bounded context has no index file and this repository has no shop directory, when the person founds this bounded context with a context id and a context purpose, the upgrades service shall keep an index file that has the context purpose and complete the request.

### upgrades model

```model
object context purpose kind of text

service upgrades
  operation found(bounded context, context id, context purpose)  outcomes: done | refused: bounded context with no context id, context id not a bounded context id, index file present, shop directory present

object index file
  relations: has → context purpose (one)
```

- **context purpose** (noun) → object context purpose. What a bounded context is for, in a sentence or two, given when it is founded and written under the `## Purpose` heading of its index file. Plural: context purposes.
