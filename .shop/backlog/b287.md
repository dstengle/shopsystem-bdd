# value-compare and value-same over two entries of one attribute word: the release of a repository compared with the release of a tool

## Notes

Fixes batch-35 defect-1 (.shop/batches/35/defect-1.md) of b275: spec_rgl_np builds T_CmpT and T_SameAs from one attribute entry, so 'the release of this repository is after the release of `migrate`' does not parse, though b275's note and grammar/language.md say two entries of one word with one value order compare. b284 (migration-tools r77-r79 reworded) waits on it.
Builds: two senses (entries) of one attribute word compare. Confirmed: model parse of 'While the release of this repository is after the release of `migrate`, when the SessionStart hook runs `migrate status --hook`, `migrate` shall print `update the plugin`.' stops after 'the release of' with only repository following, because spec_rgl_np builds T_CmpT and T_SameAs from one attribute entry. The fix is in the grammar and its readers, never in the term entries: spec_rgl_np generates value-compare ('the T of x is (not) after|before the T of y') and value-same ('is (not) the same as') over each pair of entries of one attribute word whose value orders are the same (the same `Order:`, or the same `Type:`), x and y each of its own entry's owner kind; spec_lf_order gives the form's one atom cmp(T(x1), after, T(x2)) whichever entry each side is; spec_lf_facts_atoms and check.lp's ccmp2 read the pair over the shared points of the one value order (one T id per word, or the pair of entries' ids mapped onto one order's cells); spec_steps4's Givens give each side a value of its own entry that meets the comparison. Two entries of one word with different value orders (by number against as listed, or a Type: against another or none) are refused naming the term (spec_grammar4, by spec_lf_order), for value-compare and value-same alike. The new relation row value order of sense (one) lets the lines say each sense's order. grammar/constructs.md's value-compare and value-same examples (or a second example of each, model_constructs_table) must show two entries of one word, e.g. the release of a repository against the release of a tool, in the catalogue's context, so that model constructs --check proves it. Fixes batch-35 defect-1 (.shop/batches/35/defect-1.md) of b275 (delivered). b284 (migration-tools r77-r79 reworded over 'the release of `migrate`') depends on this item. Left out: comparisons of two different attribute words, and number words between two values. The person's words: quote-29, quote-30, quote-31. Rated: high value, because b284 and migration-tools' release check wait on it and b275's note promised it; high urgency, because it fixes a defect of a delivered item; medium size, because it changes the generation of two constructs and their reading in the form, the check and the steps, and the catalogue.
