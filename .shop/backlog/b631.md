# The old command names print a notice that shop replaces them

## Notes

Split from b575 (quote-83, decision 0132). A chore, after b629 and b630 so the plugin's own texts never set it off: work, spec, measure, migrate, tools and features run by their old names print one notice on stderr, '<name>: now `shop <name>`; `<name>` goes in the next release', then run as before (output and exit unchanged); run by shop, none. Technical call: the CLI adapter contract and the scenarios keep the old names until b633, so the scenario harness and the tests that read stderr allow the notice. CHANGELOG names the aliases and the release they go in.
Rated: low value (tells a person of the new name), low urgency, small size (six entry points and the tests that read stderr).
