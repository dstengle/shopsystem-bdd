# Grammar 4's R2 binds a definite in a modifier to the noun it modifies

## Notes

Found writing b153 (reword requests): in 'When the person runs `work request --raised-for` on a request, `work` shall write a request raised for the request.' (requests#r59) model parse --form gives raised for(x5, x5): 'the request' binds to the new request whose modifier holds it, the latest earlier referent, not the trigger's request, so the line says a request is raised for itself. R2 should pass over the referent whose noun phrase the definite is part of (spec_lf_read). Until then the line reads wrong and features generate finds no step of it.
