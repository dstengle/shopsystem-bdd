# A term's part of speech fits the element it names

## Notes

New-user trial 3 of 2026-11-26 (quote-104): accepted by work line --term and never reported by spec check --item: '(verb) → object plot', '(noun) → operation garden.request', '(verb) → object tool', '(adjective) → service shed'. A noun names an object, a verb an operation or relation, an adjective a value, a proper noun an actor. MAJOR
New-user trial 3 of the product layer, the person's words in quote-104: a term whose part of speech does not fit the element its arrow names (a noun not of an object or a value, a proper noun not of a service or an actor, an adjective not of a value, an attribute not of an attribute, a verb, action not of an operation, a verb, state not of a relation) is a lexicon problem spec check fails on naming the term, and work line --term and --reword-term refuse it naming the term, as drafting r99 and r100 refuse v_t4, v_t7, v_t11 and v_t19 (b810). Technical call: a new lexicon rule beside v_t18-v_t21 in spec_vocabulary, its code given by the build and catalogued (the lines name no code, as checking r101 named no v_m9).

## Requirements

### checking

#### [g157] A term whose part of speech does not fit the element it means fails the check
- [r157] While a term means an element that the term does not fit, if the person validates this specification, then the specification service shall fail the check and name the term.

### drafting

#### [g101] A term whose part of speech does not fit the element it means is refused
- [r101] While a term means an element that the term does not fit, if the person writes the term into an item, then the drafting service shall refuse the request and name the term.

### specification model

```model
object term
  relations: fits → element (many)
```

- **fit** (verb, state) → relation term.fits. The part of speech of a term is one that an element of its kind takes: a noun an object or a value, a proper noun a service or an actor, an adjective a value, an attribute an attribute, a verb of action an operation and a verb of state a relation. Forms: fits, fitted. Frame: <term> fits <element>.
