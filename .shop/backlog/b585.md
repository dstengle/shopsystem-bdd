# Tracking's allocate, deliver, restore and suspend declare their refusals

## Notes

batch-88 review 1 observation: the model gives allocate, deliver, restore and suspend outcomes: done only, while their commands refuse an item whose status is not the move's; declare refused: item not ready / item not in-batch, with lines for them.
batch-88 review 1 observation: the domain model gives backlog's allocate, deliver, restore and suspend outcomes done only, while their commands (backlog_lifecycle via backlog_moves.moved) refuse an item whose status is not the move's. Declared: allocate refused: item not ready; deliver, restore, suspend refused: item not in-batch; one line each, as items#r32 says reopen's refusal.
Each line names the declared reason, so its scenario fails until the refusal of backlog_moves.moved carries the operation's reason (item not ready, item not in-batch) in its message and its envelope.

## Requirements

### items

#### [g60] Only a ready item is allocated
- [r60] While an item is not `ready`, if a session allocates the item, then the backlog service shall refuse the request and name the item and the `item not ready` reason.

#### [g61] Only an item in a batch is delivered
- [r61] While an item is not `in-batch`, if a session delivers the item, then the backlog service shall refuse the request and name the item and the `item not in-batch` reason.

#### [g62] Only an item in a batch is restored
- [r62] While an item is not `in-batch`, if a session restores the item, then the backlog service shall refuse the request and name the item and the `item not in-batch` reason.

#### [g63] Only an item in a batch is suspended
- [r63] While an item is not `in-batch`, if a session suspends the item with a question, then the backlog service shall refuse the request and name the item and the `item not in-batch` reason.

### tracking model

```model
service backlog
  operation allocate(item)  outcomes: done | refused: item not ready
  operation deliver(item)  outcomes: done | refused: item not in-batch
  operation restore(item)  outcomes: done | refused: item not in-batch
  operation suspend(item, question)  outcomes: done | refused: item not in-batch
```
