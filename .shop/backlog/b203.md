# A universal condition's grammar falls back to the index's marker when spec/universal.md is absent

## Notes

work line --universal creates a missing spec/universal.md with language: codified-1 (backlog_forms.py), and spec_language.four(..., universal=True) reads only that file's marker, so a fully codified-2 context with no universal.md has its universal conditions read in the old grammar. The created file's marker should follow spec/index.md, or four should fall back to the index's marker when the file is absent (review of plan-cnl4-foundation, finding 2).
