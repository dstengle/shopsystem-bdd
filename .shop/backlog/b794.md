# spec assign refuses a bounded context the product does not declare

## Notes

New-user trial of 2026-11-26 (quote-103): spec assign bad5 --to example.org/chores/nowhere printed 'assigned the job bad5 to the bounded context example.org/chores/nowhere', making the context; --addresses refuses an unknown subdomain, assign should likewise.
New-user trial on an empty project: spec assign --to a bounded context the product does not declare kept the assignment and made the context; it is to be refused naming the bounded context, as declaring a context refuses an unknown subdomain. The person's words in quote-103 and quote-104.
Ratings: value 3, a typo in --to silently makes a context and splits the product's map; urgency 3, met by every new user declaring the product; size 1, one refusal reason and one line.

## Requirements

### product

#### [g37] A job assigned to a bounded context the product does not hold is refused
- [r37] If the person assigns a job to a bounded context that is not in the product, then the product service shall refuse the request and name the bounded context.

### specification model

```model
service product
  operation assign(job, bounded context)  outcomes: done → the job | refused: job assigned already, bounded context outside the product
```
