# tools install and tools probe reach the grammar tools in a project with no source file yet

## Notes

UX trial 2026-11-19 (a checklists CLI bootstrapped from an empty repository at 0.39.0): in an empty repository (and in getting-started step 2's folder holding only a virtualenv) `tools install` and `tools probe` exit 1 with `no analysis tools are known for this project's language (looked for Python)`: the grammar tools are neither installed nor probed. The language's analysis tools may be absent; GF, pgf, clingo and the RGL are still to be installed and their block printed.
Lines in toolchain: with no Python file in the repository, install installs the grammar tools (gf-rgl) and probe returns them and completes; the analysis tools of a language with no source file are not a refusal. quote-58/directive-10 onboarding.

## Requirements

### toolchain

#### [g18] An install in a repository with no Python file installs `gf-rgl`
- [r18] While no Python file exists and `gf-rgl` is `missing` and the environment of the Python interpreter is `virtualenv`, when the person installs the toolchain, the toolchain service shall install `gf-rgl` and complete the request.
