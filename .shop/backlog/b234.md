# work ready readies an item whose lines are only universal conditions

## Notes

Gap of plugin 4.0's tooling found readying b155 (I23b, design .shop/records/2026-11-09-cnl-4/design.md I0, I19, call 15): b155's lines are all universal conditions (`### universal`, U12-U16 retiring U4, U5, U7, U8, U11), and `work ready b155` refuses it with "it has no requirement line: give it one with `work line`", because readiness_bar.check counts only capability requirements (backlog_section.ids gives `<capability>#r<n>` of the capability blocks, never the universal block's U ids). Needed: an item whose `### universal` block holds a condition (or a `language:` or `retired:` line) has lines for the bar, which then parses each condition in spec/universal.md's own grammar, runs model logic and features generate with them laid in, as it does for an item that has a capability line beside them.
