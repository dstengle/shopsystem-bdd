# spec reports the coupling between the contexts a shop hosts

## Notes

per pair of contexts: shared words, model references, lines using another context's words, code imports, with the top offenders. Part of the disentangling of this repository into hosted contexts (decisions 0129-0133).
The coupling between the parts of this repository that the disentangling (decisions 0129-0133) is to make bounded contexts, reported by the specification service: a new operation report coupling(shop) of the specification service (capability checking, area specification), returning every coupling, each joining two areas and holding what couples them.

## Requirements

### checking

#### [g141] the coupling report names the words two areas share
- [r141] While an area holds a term that has a word and another area holds a term that has the word, when the person reports on the shop, the specification service shall return a coupling of the area that holds the word.

#### [g142] the coupling report names the elements one area's model refers to of another's
- [r142] While an area holds an element that refers to a term and the term means an element that another area holds, when the person reports on the shop, the specification service shall return a coupling of the area and name the element.

#### [g143] the coupling report names the requirements that use another area's words
- [r143] While an area holds a capability and the capability has a requirement that uses a term and another area holds the term, when the person reports on the shop, the specification service shall return a coupling of the area that holds the requirement.

### specification model

```model
service specification
  operation report coupling(shop)  outcomes: returned → every coupling

object coupling
  relations: holds → word | element | requirement (many)

object word kind of text

object term
  relations: has → word (one)

object area
  relations: has → coupling (many)
```

- **report** (verb, action) → operation specification.report coupling. The person asks how the areas of a shop depend on one another: the words they share, the elements one area's model names of another's, and the lines that say another area's words. Forms: reports, reported. Frame: <actor> reports on <shop>.
- **coupling** (noun) → object coupling. What ties one area of the domain model to another: each word both define, each element the other's model names of the area's and each requirement of the other that says a word of the area. Plural: couplings.
- **word** (noun) → object word. The written form of a term, as `list`, that entries of several areas may share. Plural: words.
