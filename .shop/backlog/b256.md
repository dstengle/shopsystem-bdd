# The plugin's pytest plugin marks unbuilt scenarios under pytest-bdd 9, and runs with pytest 9.2

## Notes

Found while writing docs/getting-started.md (b170, 2026-11-11): with pytest-bdd 9.0.1, -p work_items marks nothing as an expected failure, because spec_unbuilt.mark reads item.function.__scenario__, which pytest-bdd 9 no longer sets; with pytest 9.2.0 and pytest-bdd 8.1.0 every scenario fails with AttributeError: 'FixtureManager' object has no attribute '_arg2fixturedefs'. The getting-started page pins pytest==9.1.1 and pytest-bdd==8.1.0 meanwhile; the README's requirements give no versions.
