# The shared vocabulary layer is split by element

## Notes

spec/vocabulary/shared.md's 79 entries name elements of all six areas: each moves to the layer of its element's owner, with imports added where lines need them; shared.md is a hidden shared kernel. Part of the disentangling of this repository into hosted contexts (decisions 0129-0133).
Decisions 0129-0133. Waits on b607, which gives work line --move-term (an entry out of its layer into the layer of the area that declares its element, with the imports the lines then need): each of shared.md's 79 entries moved so, shared.md left empty and gone, no requirement line changed; drafted once b607 is delivered, and ready then. The five base kinds' entries (file, text, version, repository, bounded context) are b618's, not moved here.
Rated: medium value (removes the hidden shared kernel), medium urgency, small size (moves only, no code). Not ready: its moves cannot be drafted until b607's --move-term exists.
