## Requirements

### records

#### [g3] `work record` keeps a record about an item or a batch
- [r3] When the person files a record with a text that denotes an item, the records service shall keep the record that concerns the item.

#### [g4] `work record` refuses an `--about` that denotes no node, item or batch
- [r5] While a text denotes no node and the text denotes no item and the text denotes no batch, if the person files a record with the text, then the records service shall refuse the request and name the text.

#### [g5] `work record` keeps a record about a batch
- [r6] When the person files a record with a text that denotes a batch, the records service shall keep the record.

### specification model

```model
object node

object text
  relations: denotes → node | item | batch (many)

object record
  relations: concerns → node | item | batch (one)
```

- **node** (noun) → object node. A thing of the design model that `spec` gives an id, such as a capability, a requirement or a design-decision.
- **denote** (verb, state) → relation text.denotes. A text is the id of a node, an item or a batch that this repository holds. Forms: denotes, denoted. Frame: <text> denotes <to>.
- **concern** (verb, state) → relation record.concerns. A record concerns the node, the item or the batch that it is kept about. Forms: concerns, concerned. Frame: <record> concerns <to>.
