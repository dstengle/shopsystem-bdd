# work batch review accepts work batch amend's own commits, and the amend's unbuilt ids leave the batch branch when the task builds them

## Notes

Seen in batch-95: after work batch amend b593 laid checking#r94, work batch review refused the amend's lay commit on batch-95-b593 as citing no open finding (batch_fix.check), and once the task built r94 the merge kept unbuilt: [r94] on batch-95 (the amend's lay commit on the batch branch is not an ancestor of the task branch, so git saw no change to undo), giving a strict XPASS. The driver added Finding: f1 to the amend commit by hand and took r94 out of unbuilt on batch-95 in a commit of its own.
Two faults of batch-95's fix loop: an amend made to fix a review finding should be for that finding so the review accepts it (amend takes the finding), and an amendment's line the task built must not stay unbuilt on the batch branch after the merge. Scenarios must fail before the fix.

## Requirements

### batches

#### [g113] An item amended with a review finding keeps a change for the finding, which its review accepts
- [r113] While an item in a batch is `in-batch` and a review of the batch holds a review finding, when the person amends the item with the review finding, the batches service shall keep a kept change for the review finding.

### reviews

#### [g13] A batch whose amended line its task built is submitted with the line built
- [r13] While an item in a batch is `in-batch` and every task of the batch is `done` and the workspace of the batch holds an amendment that cites the item and a scenario of the item succeeds in the workspace of a task of the item, when the person submits the batch, the batches service shall keep a proposed change of the batch and set the status of the batch to `in-review`.

### execution model

```model
object amendment kind of kept change

service batches
  operation amend(item, review finding)  outcomes: done | refused: item not in batch
```

- **amendment** (noun) → object amendment. A kept change that work batch amend makes on the workspace of a batch or of its task, laying an amended item's requirements again. Plural: amendments.
