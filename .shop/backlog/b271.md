# Retire a live requirement with no line replacing it

## Notes

Today work line --retires <cap>#r<n> "<line>" (b128) retires a live requirement only by giving it a replacement line. An item should also be able to retire a requirement outright: its id written under the capability block's retired:, the line (and its group when it was the last) taken out of Behaviour when laid, put back when unlaid, its scenario removed by features generate, no new id. Distinct from b14, which changes an item's own lines before they are built.
