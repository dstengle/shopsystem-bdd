# A second line of an item joins its group of the same title

## Notes

batch-87 (b581): work line with no --group and no --in opens a new group titled with the item's title, so a second such line gives the item two groups of one title, which items#r55's readiness bar now refuses. Have the default join the item's existing group of that title, or refuse the line when it is written.
