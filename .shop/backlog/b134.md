# The base grammar: options in the trigger, the aspect refusal

## Notes

Design record .shop/records/2026-11-09-cnl-4/design.md, section 10.3 I7b (and call 3, section 5; call 11, the CLI pack): the CLI pack's run with an option in the trigger ("runs `work backlog` with the `--json` option") parsed in grammar 4, and an action verb in a While clause or a state verb in a trigger refused, by the aspect the glossary marks on each verb; both added to the grammar 4 corpus. ## Requirements

### design-model-check

- **misaspected** (adjective of requirement): a requirement with an action verb in its While clause or a state verb in its trigger.
- **optioned** (adjective of requirement): a requirement whose trigger runs a command with an option, as in "runs `work backlog` with the `--json` option".

#### [g71] `model parse` refuses a verb of the wrong aspect for its clause
- [r71] If the person runs `model parse` on a requirement that is misaspected, then `model` shall exit with an error naming the term.

#### [g72] `model parse` passes a trigger that runs a command with an option
- [r72] When the person runs `model parse` on a requirement that is optioned, `model` shall exit successfully.
