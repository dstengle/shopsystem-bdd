# The readiness bar counts an item's universal conditions as lines, so an item whose only line is a universal condition is checked, not refused as lineless

## Notes

readiness_bar.well_formed counts only capability requirement ids, so an item whose only line is a universal condition (work line --universal, e.g. b60's U20) is refused as having no requirement line and never reaches the parse, logic and features stages; its universal conditions are to count as its lines, the person's words in quote-70

## Requirements

### items

#### [g53] A shaped item whose only lines are universal conditions that have a translation is readied
- [r53] While an item is `shaped` and the item holds a universal condition and the item holds no requirement and every universal condition in the item has a translation, when the person readies the item, the backlog service shall set the status of the item to `ready`.

#### [g54] An item whose only lines are universal conditions is checked, naming a universal condition that has no translation
- [r54] While an item is `shaped` and the item holds no requirement and a universal condition in the item has no translation, if the person readies the item, then the backlog service shall refuse the request and name the universal condition.
