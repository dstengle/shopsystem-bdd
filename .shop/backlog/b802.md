# migrate init warns when the repository's branch is not main

## Notes

New-user trial of 2026-11-26 (quote-103): git init gave master; migrate init committed on it without a warning though the skill says git init -b main.
From the new-user trial (quote-103): git init gave master and migrate init founded the context there with no warning, though the skill says git init -b main; the person asked to shape and build the trial's findings first (quote-104). Founding names the branch checked out when it is not the base branch, and still founds.
Rated: medium value, a context founded on master misleads the batches that fork from main; medium urgency, in the wave of the trial's findings; small, one warning in migrate init.

## Requirements

### upgrades

#### [g46] A bounded context founded on a branch other than the base branch names the branch
- [r46] While the branch differs from the base branch and this bounded context has no index file and this repository has no shop directory, when the person founds this bounded context with a context id, the upgrades service shall keep the context scaffold of this repository, name the branch and complete the request.

### upgrades model

```model
object branch
  relations: differs from → base branch (one)
```

- **branch** (noun) → object branch. The git branch checked out in a repository. This: the branch checked out in the repository the request is made in.
- **differ** (verb, state) → relation branch.differs from. A branch is another branch than the base branch of its repository. Forms: differs, differed. Frame: <branch> differs from <base branch>.
