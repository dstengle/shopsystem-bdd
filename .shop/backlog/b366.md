# data schemas made from the domain model and the HTTP adapter's OpenAPI document checked against it, as plugin commands

## Notes

The contract artifact (.shop/records/2026-11-19-rest-contract/) does both with record scripts (generate_schemas.py, check_adapters.py): JSON Schema 2020-12 of objects, requests, envelope responses and events from domain_model, and an OpenAPI 3.1 interface contract checked both ways like cli.toml's v_a1-v_a4. Wanted in the plugin: a spec command that writes and checks spec/schemas/ from spec/model/, spec check reading spec/adapters/http.openapi.yaml, a parameter form saying data passed rather than a reference ('<name> (passed)'), and attributes for the things a contract holds (term, requirement, design-decision) so their content is data, not {reference, text}.
