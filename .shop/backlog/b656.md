# An event or an actor restated in place keeps its continuation lines

## Notes

batch-101 review 1 observation: backlog_model's merged replaces only the first line of a lone element (event, actor); an indented continuation line of the old one stays and the restatement's is dropped, and unrestate_lone puts back only one line. Treat the lone element as body[at:_end(body, at)].
