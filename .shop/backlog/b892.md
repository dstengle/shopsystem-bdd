# A task's changes kept at submit are its own commits', not another in-batch item's merged into its branch

## Notes

From batch-178 review 2: batch_merge._kept diffs every owned path since the task's lines commit, so a task branch that merged an earlier task's branch carries that item's apply outputs, which can conflict with the rebuild and refuse the submit.
