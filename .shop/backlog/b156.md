### migration-tools

language: codified-2

- **old-layout directory** (noun): a directory of the old system's layout at the root of a repository: `decisions/`, `work/`, `records/`, `docs/superpowers/plans/`, `docs/superpowers/specs/`, `docs/superpowers/requests/` or `adrs/`. Kind of: file.
- **mention** (verb, state): a text holds the path, a relative link to or the id of a thing. Forms: mentions, mentioned. Frame: text mentions thing.
- **decision ledger** (noun): the old system's ledger of decisions, the file `spec/decisions.md`. Kind of: file.
- **ledger entry** (noun): one entry `## decision/<name>` of a decision ledger. Plural: ledger entries. Kind of: text.
- **supersede** (verb, state): a ledger entry names another, whole or in part, as the one it takes the place of. Forms: supersedes, superseded. Frame: ledger entry supersedes superseded entry. Frame: design-decision supersedes design-decision.
- **superseded entry** (noun): an entry of a decision ledger that another ledger entry supersedes. Plural: superseded entries. Kind of: text.
- **qualifier** (noun): the words after the id a ledger entry supersedes, as `(in part)`. Kind of: text.
- **number** (noun): the `<nnnn>` before the name of a ledger entry. Kind of: text.
- **next number** (noun): one above the highest number of the ledger entries of a decision ledger. Kind of: text.
- **Behaviour line** (noun): a line of the `## Behaviour` of a capability of the old system. Kind of: text.
- **line id** (noun): the `[r<n>]` of a Behaviour line. Kind of: text.
- **next id** (noun): one above the highest line id a capability has used or retired. Kind of: text.
- **destination** (noun): the path `migrate run` relocates a file to or writes a file at. Kind of: file.
- **plugin version file** (noun): the file `.shop/plugin-version`, one line naming the plugin release a repository is on. Kind of: file.
- **version** (noun): a plugin release written `<major>.<minor>.<patch>`. Kind of: text.
- **content** (noun): the text a file holds. Kind of: text.
- **shop directory** (noun): the directory `.shop/` of a repository. Kind of: file.
- **upgrade step** (noun): one step of `migrate upgrade` from one plugin release to the next, named by its title. Kind of: thing.
- **lack** (verb, state): a repository is on a release before the release of an upgrade step, so the step is pending in it. Forms: lacks, lacked. Frame: repository lacks upgrade step.
- **the ids step** (proper noun): the upgrade step "work-items named by ids" of release 0.24.0. Kind of: upgrade step.
- **the answers step** (proper noun): the upgrade step "answers, not rulings" of release 0.25.0. Kind of: upgrade step.
- **the codified step** (proper noun): the upgrade step "codified requirements" of release 1.0.0. Kind of: upgrade step.
- **the simplified-workflow step** (proper noun): the upgrade step "the workflow simplified" of release 2.0.0. Kind of: upgrade step.
- **the verb-frames step** (proper noun): the upgrade step "verb frames" of release 3.0.0. Kind of: upgrade step.
- **work-item file** (noun): the file `.shop/work/<initiative>/<work-item>.md` of a work-item of plugin 1.x. Kind of: file.
- **stage directory** (noun): the directory `.shop/work/<initiative>/runs/<work-item>/` of a work-item's stages. Kind of: file.
- **initiative log** (noun): the file `.shop/work/<initiative>/log.jsonl` of an initiative of plugin 1.x. Kind of: file.
- **restated file** (noun): the file `spec/restated.json`, the 0.29 requirements by id. Kind of: file.
- **language** (attribute of capability): the marker `language:` of a capability's frontmatter, `uncodified` when it has none. Values: `uncodified`, `codified-1`, `codified-2`.
- **tag** (noun): a Gherkin tag of a scenario, as `@deprecated`. Kind of: text.
- **frozen notice** (noun): the file `.shop/work/FROZEN.md`, which says that the queue of plugin 1.x is frozen. Kind of: file.
- **frozen request** (noun): a request of plugin 1.x under `.shop/work/requests/`. Kind of: file.
- **peer request** (noun): a frozen request that another bounded context asked. Kind of: frozen request.
- **internal request** (noun): a frozen request that the bounded context asked of itself (its asker `internal`). Kind of: frozen request.
- **status** (attribute of frozen request): a frozen request's place in the lifecycle of a request of plugin 1.x. Values: `open`, `awaiting-asker`, `awaiting-upstream`, `accepted`, `delivered`, `refused`, `withdrawn`.
- **the first release** (proper noun): the release `0.23.1`, which `migrate` takes a repository with a shop directory and no plugin version file to be on. Kind of: version.
- **the no-step note** (proper noun): "no upgrade step is pending", what `migrate upgrade` prints when this repository lacks no upgrade step. Kind of: text.
- **the yes-only note** (proper noun): "only on the person's yes", the SessionStart hook's note that a session runs a pending upgrade only on the person's yes. Kind of: text.
- **the update note** (proper noun): "update the plugin", the SessionStart hook's note to a session in a repository on a release newer than the plugin's. Kind of: text.
- **the no-version note** (proper noun): "holds no version", the SessionStart hook's note on a plugin version file that holds no version. Kind of: text.
