# The fix task step names the task the failure belongs to and asks for a commit the review accepts

## Notes

batch-120 review on b696: when the failing tests match no item's scenario and no task's change, fix task falls back to the first task; after a review is recorded, the step asks for a commit citing only Item:, which work batch review refuses (commits since a review must cite an open finding).

## Requirements

### execution model

```model
object batch step
  attributes: instruction: prepare task | build task | finish task | submit batch | review change | fix finding | fix task | look at failure | park item | stop
  relations: holds → task | batch brief | review folder | findings file | review finding (many)
```

- **look at failure** (noun) → value batch step.instruction look at failure. A batch step that asks the driver to look at the scenarios that broke a submit when they are of no task's item, with no task to fix named.
