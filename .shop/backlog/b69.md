# A person's comment on a batch's pull request reopens the batch with a finding

## Notes

From the person's comment on PR #24 (batch-9, awaiting-merge, 2026-11-06), which asked for recovery when a post succeeds and the commit recording its URL fails. No command takes a batch that is awaiting-merge back to review with the person's finding: work batch brief and reviewed take only an in-review batch, and a fix commit must cite an open finding of a recorded review. For batch-9 the batch file's status was set back to in-review by hand, and the person's comment was saved as review 3's findings file. Wanted: a command (for example work batch reopen <batch> --finding <file>, or reviewed taking a person's findings) that records a person's pull-request comment as a review with a fix-now finding and sets the batch to building.
