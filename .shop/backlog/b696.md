# The batch poll gives a step for a submit the whole suite refused

## Notes

batch-117: work batch done passed on the tests the task's change reaches, then work batch review's whole-suite run failed; work batch next answered 'submit batch' again instead of a step to fix the failing task (send the failure to the item whose change broke it).

## Requirements

### execution model

```model
object batch step
  attributes: instruction: prepare task | build task | finish task | submit batch | review change | fix finding | fix task | park item | stop
  relations: holds → task | batch brief | review folder | findings file | review finding (many)
```

- **batch step** (noun) → object batch step. What a batch needs done next, as the batches service says it to the driver: its instruction and the task, brief, review folder, findings file or finding it is about.
- **instruction** (attribute) → attribute batch step.instruction. What a batch step asks the driver to do.
- **prepare task** (noun) → value batch step.instruction prepare task.
- **build task** (noun) → value batch step.instruction build task.

### retirements

- model line `object batch step` in execution
