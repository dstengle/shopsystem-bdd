# spec trace keys a provider's requirement by its provider, so a provider id equal to a local one is neither hidden nor misread

## Notes

batch-133 review 1's observation on b637 (scripts/product_trace.py provided/own/joined): a provider requirement is keyed by its bare id; one equal to a local id is dropped by own, two providers' equal ids fold into one in joined, and product_coordination and model_product look it up in this context's facts. Qualify the key with the provider id or keep provider requirements apart.
Own (batch-133 review observation on b637). product_trace keys a provider's requirement (provided) by its bare id, so own drops one whose id equals a requirement of the trace (r[0] in held), joined folds two providers' equal ids into one, and model_product's read_traces and product_coordination take a provider id as a line of this context.
