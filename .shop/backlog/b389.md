# A fresh context's first batch: the skills and the batch brief say how its step bindings, program and adapter contract are made

## Notes

UX trial 2026-11-19 (a checklists CLI bootstrapped from an empty repository at 0.39.0): after `work batch start` laid six lines, the brief's acceptance tests ran against nothing: no step definitions, no program, no spec/adapters/cli.toml (`spec annotate` and `--check` exit 0 silently without one); only getting-started step 7 shows a hand-written pytest-bdd module. The brief's acceptance command omits `-p work_items`. No skill fires between `migrate init` and a first item (shaping-items needs a codified spec), so a session bootstrapping a context has nothing to follow.
