# Parking an item whose model line restates an operation identically keeps the operation

## Notes

batch-61 review-1 observation (b463): backlog_model_ops.restated treats an identical line as a restatement; the unlay walks history to before the operation existed and removes it. Same for a model line that repeats an operation unchanged.

## Requirements

### batches

retired: [r88]
retires: [r89 r88]

#### [g89] An item parked puts back the operation its model line restates
- [r89] While an item in a batch is `in-batch` and the item holds a model line that restates an operation and the domain model holds the model line, when a session parks the item, the batches service shall keep a domain model that holds the operation.
