# A task holding only an amend's laid commit is not read as built by the batch poll

## Notes

batch-118 review on b692: a commit work batch amend lays on a task branch cites the item, so a task with only that commit reads as built and gets 'finish task'; leave out commits that carry a Laid: line. Also CLAUDE.md's readiness_handlers_imports row does not name items r70 (b694).

## Requirements

### batches

#### [g149] A running task whose only kept change citing its item is an amendment asks the driver to build it
- [r149] While a batch is `building` and a task of an item in the batch is `running` and the item is `in-batch` and the workspace of the task holds an amendment that cites the item and the workspace of the task holds exactly one kept change that cites the item and no task of the batch is `failed`, if the driver polls the batch, then the batches service shall return a batch step whose instruction is `build task`, the task and the batch brief of the batch.
