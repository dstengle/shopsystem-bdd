# The product's domain map: subdomains, contexts, job assignments and actor mapping

## Notes

Decisions 0128, 0141, 0143. The domain map of the product: subdomains with their type (core, supporting, generic) and the jobs they serve; the bounded contexts with the subdomains each addresses and the shop that hosts it, or none for a third-party provider (0143); each job assigned to one bounded context (a reassignment keeps the earlier one as history); per bounded context the term (an actor of its model) that plays each product actor (0141). Technical calls: operations of the product service (b602), CLI spec subdomain, spec context, spec assign, spec plays. Needs b602's product and jobs and b576's hosted contexts.
Rated: high value (the domain map replaces areas' subdomain kinds, b615), medium urgency, medium size (about seven lines: subdomain, context entry, assignment, actor mapping and their refusals). Lines in the product capability once b602 is delivered.

## Requirements

### specification model

```model
object product
  relations: holds → subdomain | bounded context (many)

object subdomain
  attributes: type: core | supporting | generic
  relations: has → id (one); serves → job (many)

object bounded context
  relations: addresses → subdomain (many); is hosted by → shop (one)

object id
  relations: covers → id (many)

service product
  operation declare subdomain(subdomain, id, type, job)  outcomes: done → the subdomain | refused: type not a subdomain type, job outside the product
  operation declare context(bounded context, id, subdomain, shop)  outcomes: done → the bounded context | refused: id outside the product, subdomain outside the product
```
