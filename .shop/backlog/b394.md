# work batch start says before it starts when there is no remote or gh to publish the batch with

## Notes

UX trial 2026-11-19 (a checklists CLI bootstrapped from an empty repository at 0.39.0): `work batch start` started batch-1 in a repository with no remote; `work batch review` needs a remote and gh to publish it, and getting-started tells a new user gh is not needed yet. The start could warn, or the docs say a batch needs both.
