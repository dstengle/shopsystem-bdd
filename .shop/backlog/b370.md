# The grammar's definition is the source of truth: construct-by-construct and rule-by-rule lines replaced by the catalogues as specification artifacts

## Notes

The person (2026-11-19): many lines in reading.md are derivable from the grammar definition; they record how the grammar came to behave a certain way, which is not definition, as an object's attributes are not each stated as a requirement. Today the same fact is stated four times: the GF sources and generated Context, grammar/constructs.md (generated, examples parsed), grammar/language.md (R1-R12 with tested lines) with the corpus, and reading.md's 61 lines (e.g. r14 'parses a requirement that uses no-noun ... shall complete the request'). checking.md has 47 lines, 22 naming a rule code that grammar/rules.md already catalogues with fail/pass examples. #### [g48] A violation of a rule fails the check under the rule's code
- [r48] While a capability violates a rule whose severity is `error`, if the person validates this specification, then the specification service shall fail the check and name the rule.

#### [g49] A warning is named and the check passes
- [r49] While a capability violates a rule whose severity is `warning` and nothing violates a rule whose severity is `error`, when the person validates this specification, the specification service shall name the rule and complete the request.

#### [g50] A requirement that uses a rule the rule catalogue does not define fails the check
- [r50] While a requirement uses a rule that has no catalogue entry, if the person validates this specification, then the specification service shall fail the check and name the rule.

#### [g51] A catalogue entry with no purpose fails the check
- [r51] While a catalogue entry has no purpose, if the person validates this specification, then the specification service shall fail the check and name the catalogue entry.

### specification model

```model
object rule
  attributes: severity: error | warning

object purpose kind of text

object catalogue entry kind of text
  relations: has → purpose (many)
```

- **purpose** (noun) → object purpose. What a catalogue entry says its construct or rule is for, in a sentence or two. Plural: purposes.
- **severity** (attribute) → attribute rule.severity. Whether a violation of a rule fails the check or is only named.
- **error** (noun) → value rule.severity error.
- **warning** (noun) → value rule.severity warning.
