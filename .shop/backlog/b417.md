# The UserPromptSubmit hook keeps the session in a repository migrate init founds in that same turn

## Notes

UX trial 2 (2026-11-20, 0.40.0): the hook keeps a session only where .shop/ exists, so in a fresh repository the person's first words (said in the turn that ran migrate init) gave 'work quote: no session is known'; the session found its transcript under ~/.claude/projects and passed --transcript. migrate init could keep the pointer for the session that ran it, or the refusal name --transcript and where transcripts are.
