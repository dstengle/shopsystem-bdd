# A scenario whose Givens no test world matches fails instead of running in a default world

## Notes

b711, b716, b732 and b737 were each returned by work batch start because their new scenario passed on the lay: the tests/scenarios helpers pick a world by matching a Given's text (feature_file_tools_*, readiness_world.mine and the like) and fall back to a default world when none matches, so a new line's scenario runs in a world that cannot fail. b734 made one helper (no frame takes thing) fail loudly; do it for every helper's fallback, so a new scenario no world matches fails until its world is built.
