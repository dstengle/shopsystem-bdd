# features generate writes the Then of a negated response whose object the line gives no antecedent

## Notes

Met readying b157 (2026-11-10): feature-file-tools#r86 and #r87 (b157) say "`features` shall ... not write a scenario line of the requirement group" (R4: under shall not, "a K" is any K); `features generate` stops on their groups with "no Then of not" (spec_steps4_boxes.acts: a `not` box in a response with referents has no translation, only a negated restriction does). "write no scenario line of ..." and "not write the scenario line of ..." (a definite with no antecedent) stop the same way. A negated response over a K the line names before (r57 "not print the scenario", r64 "not write the then step") is written. Wanted: a Then that no such K is written, e.g. "no scenario line of the requirement group is written", for a negated response over an indefinite object or a "no K" in a response.
