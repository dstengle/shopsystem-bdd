# work batch start writes each new operation's CLI table (as --expose does) so the lay raises no v_a1

## Notes

An operation an item adds to the domain model with no operation table on the item leaves the lay with a v_a1 (an operation of the model with no table); work batch start writes its table from the model's operation, as work line --expose does since b482 (its writer), so the lay checks clean. From the missing-command research, the person's words in quote-68.
Rated medium-value: a batch whose item adds an operation no longer starts with a v_a1 or needs a hand-written table; medium-urgency: every new operation hits it until done; small: the lay calls b482's table writer for each operation a model line specifies that the model and the item's tables lack.
