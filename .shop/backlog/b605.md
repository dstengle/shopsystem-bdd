# A negated set is not counted as a line setting the attribute

## Notes

model_domain_lines counts batches#r111's 'shall not set the status ... to abandoned' as a set, so the in-review -> abandoned transition looks caused by a line and the w_m5 warning it should raise is hidden.
World to fail before the fix: the domain-model fixture with notes' lifecycle status draft -> active, draft -> archived where only archived... concretely a lifecycle with a transition (draft -> abandoned) that no operation performs, and a notebook line whose response says 'shall not set the status of the note to abandoned' (set-attribute, negated); before the fix model_domain_lines' _atoms walks into the not box and Lines.sets emits sets/sets_from_any, so caused() holds and w_m5 is not raised, spec check does not name the transition; the fix skips an initiates atom inside a not box (a forbidden set causes nothing).
Correction to the note above: the world is the domain-model fixture with a lifecycle transition draft -> abandoned of the note's status that no operation performs, and the negated set line; ignore the garbled 'draft -> archived' words.
