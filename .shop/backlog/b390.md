# The lay writes the construct catalogue only for a line that cites a construct, not for a backticked value

## Notes

The scenario's requirement holds a backticked value equal to a construct code (`done`, as 'set the status of the item to `done`'), which the lay counted as a citation (model_constructs.citing). directive-10 onboarding.
