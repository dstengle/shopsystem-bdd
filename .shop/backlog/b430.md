# The readiness bar answers in seconds: it parses only what a lay's change can reach, reads the model facts once, and stats the spec once

## Notes

2026-11-20: shaping b418 ran work ready four times at about 22 minutes each; the person: work ready should be something the user expects to be almost instantaneous. Measured (record 2026-11-20-the-readiness-bar-on-b418-timed): 15 s warm, 730 s with an empty cache. A lay that adds a word changes the grammar sources' sha, the parse cache's key, so every one of spec/'s 815 lines is parsed again (0.74 s each, 83% of the time), though the item has 11; the model facts, which parse every line, are read three times a run (_violations twice, annotate); 3 gf compiles of 19.5 s when the sha changes; spec_grammar4._state makes about a million stat calls (5 s of the warm 15 s). Target: a few seconds for an item of about ten lines on this repository's spec, the first run after a vocabulary change bounded by the grammar's compile. A line's parse kept while no word of it nor the base grammar changed (the key the base grammar's sha and the lexicon entries of the line's words, so a new sense of a word the line uses parses it again, b420), the facts read once, the state's files statted once a run.
