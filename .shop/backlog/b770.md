# batch_reached.reached sees an input taken out when it was the last of its folder or a provider contract

## Notes

batch-147 review 1 observation on b763: batch_reached.inputs takes spec_held.inputs(tree), which lists only files that exist, adding the folder of each listed file only under spec/. A lay that removes the last file of spec/packs/ or spec/vocabulary/, or a provider/<x>/contract.toml, is not seen (the old code passed whole folders and a provider glob). Reproduce: a fixture whose spec/packs/ holds one pack, delete it uncommitted, reached(root) returns False. Hardening; lays rarely make these deletions today.
