# work batch merged and abandon remove the batch's review folders

## Notes

On 2026-11-06 .shop/worktrees still held batch-1-review-1..3, batch-2-review-1 and batch-4..7's review folders after their batches merged: `work batch merged` and `abandon` remove the task worktrees but not `batch-<n>-review-<k>` (the brief, change.diff and findings.md, whose content is committed as .shop/batches/<n>/review-<k>.md). Left there they read as live work, and the person ruled that worktrees from older work are never reference material. Remove them with the batch's other worktrees.
Shaping (2026-11-06): a new kind, review folder, with the row `| review folder | of | batch | one |`, and one line for each command: the merge (r14) and `work batch abandon` (r15). Abandon's line names no status, since a batch back to `building` with open findings has review folders too. Folders already left by earlier batches are not this item's: they can be removed by hand.
renumbered by work batch start: batches#g14 -> batches#g16, batches#r14 -> batches#r16

## Requirements

### batches

- **review folder** (kind): the scratch directory `batch-<n>-review-<k>` under the batch's worktrees directory, which `work batch brief` writes a review's brief and change into and where the review's findings are saved; never committed.

| review folder | of | batch | one |

#### [g16] The merge removes the batch's review folders
- [r16] When the person merges the pull request of a batch, `work` shall remove every review folder of the batch.

#### [g15] `work batch abandon` removes the batch's review folders
- [r15] When the person runs `work batch abandon` on a batch, `work` shall remove every review folder of the batch.
