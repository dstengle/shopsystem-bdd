# Tell another context what this context can do

## Notes

Raised while shaping b26 (requests exchanged through GitHub issues); b26 does not wait on it.
Decided in the 2026-11-16 triage (.shop/records/2026-11-16-backlog-triage.md), quote-39: an offer is not enough. A context publishes a contract of what it provides today, so a downstream knows what is available and what is not; the offer is for functionality that does not exist yet.

## Withdrawn

Merged into b348 "A bounded context asks another for its context: its glossary, capabilities and lines, without a request for new behaviour": Its decision, to publish a contract of what this context does today (quote-39), is b348's contracts capability r1-r17; b348 is the publish and obtain step of the contracts design (decision 0117).
