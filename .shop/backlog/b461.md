# Bulk retire from a file

## Notes

From the missing-commands and new-user-flow research of 2026-11-21: 19 hand commits retired or renumbered lines in bulk (not re-run). `work line --retires-all --from <file>`. The person's words in quote-68.

## Requirements

### drafting

#### [g27] A retirement list applied to an item keeps every requirement it holds
- [r27] When the person applies a retirement list to an item, the drafting service shall keep the item and every requirement that the retirement list holds.

#### [g28] A retirement list that names a requirement id no requirement has is refused whole
- [r28] If the person applies a retirement list that holds a requirement id that no requirement has to an item, then the drafting service shall refuse the request, name the requirement id and not keep the item.

### tracking model

```model
service drafting
  operation apply(retirement list, item)  outcomes: done | refused: requirement id of no requirement

object retirement list kind of file
  relations: holds → requirement id | requirement (many)
```

- **retirement list** (noun) → object retirement list. A file of pairs, each a requirement id and the requirement that retires it, which an item takes in one request.
- **apply** (verb, action) → operation drafting.apply. Forms: applies, applied. Frame: <actor> applies <retirement list> to <item>.
