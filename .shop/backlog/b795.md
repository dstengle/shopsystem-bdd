# The product's declarations can be taken back: a job unassigned, a job, actor, subdomain or bounded context dropped

## Notes

New-user trial of 2026-11-26 (quote-103): no command undoes an assignment or drops a declaration; reassigning is refused 'job bad5 is assigned to the bounded context ... already'; a hand edit of .shop/product/product.toml was swept silently into the next spec assign commit.
The new user's trial (quote-103) found no command that takes a product declaration back: a job assigned to the wrong bounded context could not be reassigned, and a hand edit of the product file was swept into the next commit. The person asked these be shaped and built first (quote-104). Lines: a job unassigned from a bounded context; a job, a product actor, a subdomain and a bounded context dropped from the product, each refused naming what still refers to it (a job that needs it, a bounded context that holds or addresses it, a subdomain that serves it, a job that has the actor).

## Requirements

### specification model

```model
service product
  operation unassign(job, bounded context)  outcomes: done → the job | refused: job not assigned to the bounded context
  operation drop job(job)  outcomes: done → the job | refused: job a job needs, job a bounded context holds, job a subdomain serves
  operation drop actor(product actor)  outcomes: done → the product actor | refused: product actor of a job, product actor a bounded context holds
  operation drop subdomain(subdomain)  outcomes: done → the subdomain | refused: subdomain a bounded context addresses
  operation drop context(bounded context)  outcomes: done → the bounded context | refused: bounded context that holds a job
```

- **unassign** (verb, action) → operation product.unassign. The person takes a job back from the bounded context it was assigned to. Forms: unassigns, unassigned. Frame: <actor> unassigns <job> from <bounded context>.
- **drop** (verb, action) → operation product.drop job. The person takes a job out of the product. Forms: drops, dropped. Frame: <actor> drops <job>.
- **drop** (verb, action) → operation product.drop actor. The person takes a product actor out of the product. Forms: drops, dropped. Frame: <actor> drops <product actor>.
- **drop** (verb, action) → operation product.drop subdomain. The person takes a subdomain out of the product's domain map. Forms: drops, dropped. Frame: <actor> drops <subdomain>.
- **drop** (verb, action) → operation product.drop context. The person takes a bounded context out of the product's domain map. Forms: drops, dropped. Frame: <actor> drops <bounded context>.
