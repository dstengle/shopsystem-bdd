# Skills and tools for writing every kind of artifact from scratch

## Notes

Every artifact type (capability file, glossary term, relation, decision, record, request, item, ...) and every action on it gets a skill or a command, so an agent writes one from scratch without copying or reading existing ones; the person's words in quote-2.

## Requirements

### design-model-check

- **file form** (kind): one kind of file a bounded context keeps, with its path, its fields and sections, and the command or skill that writes it. Plural: file forms.
- **blank** (kind): a file of one file form with each of its fields and sections named and none filled in, that the form's reader reads without a refusal. Plural: blanks.
- **unknown** (condition of file form): a file form that `model` does not have.

#### [g55] `model forms` lists every file form
- [r55] When the person runs `model forms`, `model` shall print every file form and exit successfully.

#### [g56] `model form` prints the blank of a file form
- [r56] When the person runs `model form` on a file form, `model` shall print a blank and exit successfully.
