# Commands file a design, a plan with its design, and an observation, so no record form is written by hand

## Notes

From the missing-commands research of 2026-11-21 (b44 withdrawn): spec forms lists the design record folder, the plan record folder and the observation as written by hand. b44's 'object plan kind of record' made 'files a plan' read three ways (the record frame, the plan frame); here design and plan are objects of their own, kinds of file, not of record, and each operation of the records service takes the verb file with one frame of its own kind, so each line has one reading (checked with spec parse --item). The person's words in quote-68.

## Requirements

### records

#### [g3] `work record --design` files a design in its folder
- [r3] When the person files a design, the records service shall keep the design.

#### [g4] `work record --plan` files a plan in the folder of its design
- [r4] When the person files a plan with a design, the records service shall keep the plan and keep the design that holds the plan.

#### [g5] `work record --plan` refuses a design that does not exist
- [r5] If the person files a plan with a design that does not exist, then the records service shall refuse the request and name the design.

#### [g6] `work observe` files an observation
- [r6] When the person files an observation, the records service shall keep the observation.

### specification model

```model
object design kind of file
  relations: holds → plan (many)

object plan kind of file

service records
  operation file design(design, title, summary)  outcomes: done → the design
  operation file plan(plan, design, title)  outcomes: done → the plan | refused: design that does not exist
  operation file observation(observation, summary)  outcomes: done → the observation
```

- **design** (noun) → object design. A folder `.shop/records/<date>-<topic>/` whose `design.md` says how a piece of work is to be built; it holds the plans that carry the design out.
- **plan** (noun) → object plan. A file `plan-<k>.md` in the folder of its design: the tasks that carry out the design.
- **file** (verb, action) → operation records.file design. Forms: files, filed. Frame: <actor> files <design>.
- **file** (verb, action) → operation records.file plan. Forms: files, filed. Frame: <actor> files <plan>.
- **file** (verb, action) → operation records.file observation. Forms: files, filed. Frame: <actor> files <observation>.
