# work line --expose writes the operation table from the model's operation, no inline TOML

## Notes

work line <item> --expose takes only inline TOML tables (scripts/backlog_adapter.py expose, adapter_tables.one): exposing an operation the domain model declares means writing its [operations."<service>.<operation>"] table by hand. Given the operation alone (its operation table as the model gives it), work line writes the table from the model's operation: its command from the operation's name, each parameter an option of its name with an example of its type; r31-r33 (a table given) unchanged. From the missing-command research, the person's words in quote-68.
