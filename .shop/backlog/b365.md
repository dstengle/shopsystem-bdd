# an attribute typed (version) reads in grammar 4: 'whose version is `1.2.0`', after and before by number

## Notes

Found writing the contract artifact (.shop/records/2026-11-19-rest-contract/design.md §2): spec_vocabulary_terms passes only number, time and text types to the lexicon, and a text attribute with no values takes no code, so an attribute 'version (version)' or '(text)' gives no 'is `1.2.0`'. The contract's version is modelled as a relation to the object version for now ('a contract that has the `1.2.0` version').
