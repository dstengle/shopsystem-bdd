# The batch poll says abandon when every item of a batch is parked

## Notes

batch-125: with its only item parked, work batch next said stop, leaving the batch building with a draft pull request and no instruction; it should say abandon the batch.

## Requirements

### execution model

```model
object batch step
  attributes: instruction: prepare task | build task | finish task | submit batch | review change | fix finding | fix task | look at failure | park item | abandon batch | stop
  relations: holds → task | batch brief | review folder | findings file | review finding (many)
```

- **abandon batch** (noun) → value batch step.instruction abandon batch. A batch step that asks the driver to abandon a batch that is still building when every item it held is parked, so no item is left to build.
