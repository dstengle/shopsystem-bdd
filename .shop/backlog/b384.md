# A batch awaiting merge takes more work: reopened to building with a reason, then reviewed again

## Notes

The person (2026-11-19) asked whether there is a way to work on something after it is set to awaiting merge. There is none: `work batch reviewed` moves a batch to awaiting-merge when no finding is open, and from there only `merged` or `abandon` (which drops every item back to ready). A late finding (the person's, a failed check, a merge conflict with main) needs a command that reopens the batch to building with the reason recorded as a finding of a new review, so the fix loop (resume, done with Finding: commits, review, brief, reviewed) runs as for any review finding.
