# An item's port line names the core lines that rely on it

## Notes

Found shaping b636: its contract-registry port lines r1-r3 fail v_pb4 in work ready because an item's block cannot hold a 'Relied on by:' line (backlog_section refuses it) and the lay writes none; the bound check (decision 0126) needs it.
