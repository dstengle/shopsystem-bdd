### specification model

```model
object design kind of record

object plan kind of record

service records
  operation file plan(plan, design, title, summary, text)  outcomes: done → the plan | refused: design that does not exist
  operation observe(observation, about, text)  outcomes: done → the observation | refused: text not a node id
```

- **design** (noun) → object design. A record of how a piece of work is to be built, which its plans are kept with.
- **plan** (noun) → object plan. A record of the tasks that carry out a design, kept with its design.
- **file** (verb, action) → operation records.file plan. Forms: files, filed. Frame: <actor> files <plan>.
- **file** (verb, action) → operation records.observe. Forms: files, filed. Frame: <actor> files <observation>.
