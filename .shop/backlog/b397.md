# The user docs lead with simple prompts to the session, not commands the person runs

## Notes

From quote-58 (2026-11-19): the docs should point the user to simple prompts rather than running commands; the agent works out what to run. The person should not need to run the plugin's tools themselves: the first alpha tester looked for a command named tools on their system and found none (the plugin's commands are scripts inside the plugin, not on PATH). Read as 'should not need to run' (the quote says 'should need', taken as a slip). Scope: README and docs/getting-started.md first: each step a prompt to say to Claude Code ("set up this repository for the plugin", "I want an app that ..."), what the session will do and what the person sees; console blocks kept only in the reference pages, marked as what the session runs. Touches b388 (tools install in an empty project), b389 (first batch guidance) and b392 (skills): the skills then carry what the docs no longer show the person. Found beside the UX trial of 2026-11-19 on a checklist app.
