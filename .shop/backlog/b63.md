# push_env's tests ignore the developer's global git config

## Notes

From .shop/batches/8/review-2.md (observation, b56's fix of f1): tests/scripts/test_push_env.py's repo fixture clears $GIT_SSH_COMMAND and $GIT_SSH but not the global config, and git config core.sshCommand reads ~/.gitconfig, so test_no_ssh_setting_runs_ssh_in_batch_mode fails on a machine with a global core.sshCommand (git config --global core.sshCommand 'ssh -i k'). Set GIT_CONFIG_GLOBAL=/dev/null and GIT_CONFIG_NOSYSTEM=1 in the fixture.
