# A line removed from an in-batch item leaves its task's workspace too, not only the batch's

## Notes

batches#r82 takes a line removed from an in-batch item out of batch-<n> only; the task's branch keeps it, so the task builds a line the item no longer holds. r89 retires r82, keeping both workspaces without it, as r81 does for a laid line.
