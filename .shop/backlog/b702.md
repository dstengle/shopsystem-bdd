# The batch poll returns every task that takes the same step, so tasks are built side by side

## Notes

work batch next returns one step for one task; a batch of four tasks builds them one after another unless the driver looks further (batch-120's driver was told to check work batch status). Return each task that takes the step (build task, prepare task) in one response.

## Requirements

### batches

retired: [r145]
retires: [r152 r145]

#### [g152] A batch with unbuilt running tasks and no failed task asks the driver to build every running task with its brief
- [r152] While a batch is `building` and two tasks of items in the batch are `running` and no task of the batch is `failed` and no kept change cites an item in the batch, when the driver polls the batch, the batches service shall return a batch step whose instruction is `build task`, every task of the batch whose status is `running` and the batch brief of the batch.
