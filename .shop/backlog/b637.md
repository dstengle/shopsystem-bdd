# An adapter spec names the provider operations each port operation uses, and traces follow them

## Notes

quote-93, decision 0138: per port operation the set of provider operations used (of one provider or several), checked against the held contracts; the trace of a job follows each into the provider's contract lines.

## Requirements

### checking

#### [g132] A provider operation an adapter spec uses that no held contract declares
- [r132] While an adapter spec realises the requirement id of a port line that governs an operation and the operation uses another operation and the adapter spec holds no contract that holds the operation, if the person validates the adapter spec, then the specification service shall fail the check and name the operation.

#### [g133] A port operation of an adapter spec that uses no provider operation
- [r133] While an adapter spec realises the requirement id of a port line that governs an operation and the operation uses no operation, if the person validates the adapter spec, then the specification service shall fail the check and name the operation.

### product

#### [g35] A trace follows each provider operation an adapter spec uses
- [r35] While a requirement group serves a job and a requirement of the requirement group uses an operation and a port line governs the operation and an adapter spec realises the requirement id of the port line and the operation uses another operation and the adapter spec holds a contract that holds a requirement that governs the operation, when the person traces the job, the product service shall return the requirement.

### specification model

```model
object operation
  relations: uses → operation (many)
```

- **use** (verb, state) → relation operation.uses. An adapter spec names, for an operation of its parent's driven port, an operation of a provider's contract that it requests to realise it; an operation may use several operations, of one provider or several, and an operation of a provider may be used by several (decision 0138). Forms: uses, used. Redefines: spec. Frame: <operation> uses <operation>.
