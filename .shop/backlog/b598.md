# A model line restates an element of the domain model in place

## Notes

Shaping b590 found that an item's model lines only add to an element of the domain model, or restate an operation (b463); an object's attribute or relation can be neither taken out nor given another value (b590's contract holds design-decision, b596's availability). A model line that restates an element, laid in place of it as an operation's is, lets an item change a declared element.
Rated: high value (no item can change a declared object, attribute or relation without it), medium urgency (b590 waits on it), medium size (backlog_model's lay and unlay of an element, as backlog_model_ops does an operation's).

## Requirements

### batches

#### [g113] A model line that restates an element is laid in place of it
- [r113] While an item is `ready` and the item meets the readiness bar and the item holds a model line that restates an element, when the person opens a batch, the batches service shall keep the model line in the domain model and keep a domain model that does not hold the element.

### execution model

- **restate** (verb, state) → relation model line.restates. A model line declares an element that the domain model declares already, under the same name, with the members the element is to have in place of its own. Forms: restates, restated. Frame: <model line> restates <element>.
