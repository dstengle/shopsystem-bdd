# A model line restates an element of the domain model in place

## Notes

Shaping b590 found that an item's model lines only add to an element of the domain model, or restate an operation (b463); an object's attribute or relation can be neither taken out nor given another value (b590's contract holds design-decision, b596's availability). A model line that restates an element, laid in place of it as an operation's is, lets an item change a declared element.
