# work line --serves before a line's text takes the job, not the line as a group

## Notes

MAJOR
New-user trial 4 (the person's words in quote-104 and quote-106): 'work line <b> --into <cap> --group <t> --serves <job> "<line>"' is refused as '--serves: <job> is not a requirement group', since --serves takes one or more arguments (nargs='+') and swallows the line. Rated high-value: a MAJOR finding of the new-user trial, the documented order of --serves beside a line fails; high-urgency: directive-19 wants the docs working for the release; small: one argparse reading in backlog_serves.py, a test, a handler and a docs sentence.
