# The request chain covers a request whose parameter names a thing

## Notes

Left by batch-81 f1's fix (b545): the chain's covers compares request keys only, but a request's object term X becomes pair(...) when a parameter names a thing, so a governing line that leaves such a parameter out may still not fire in entail.lp's evC join; a code parameter keeps X the same. Make the join cover the object term too.
