# A pack's verb such as return can name the context's own operation

## Notes

Docs trial 1 of 2026-11-26 (quote-106): MAJOR: '- **return** (verb, action) → operation library.return ... Redefines: request.' still gives v_t6 'the grammar spells return itself' at work ready; the person's word must be renamed ('brings back'). Either Redefines: makes it the context's own, or the refusal says which words the grammar keeps and what to do.
From the first docs trial (quote-106: get the docs working). A vocabulary entry of the context's own that Redefines: request (the trial's 'return' of a tool library, an operation) still gets v_t6 'the grammar spells return itself' (spec_lexicon_problems: an event term in REQUEST_VERBS, Redefines not read), so the person's word had to be renamed. Investigated on a copy of docs/examples/notes-cli with '- **return** (verb, action) -> operation notes.return ... Redefines: request.': spec_rgl_vocab already drops the pack's entry for the context's own sense, so 'the person returns a note' parses as notes.return, but then 'the notes service shall return every note' silently reads as the context's return (the service requesting the operation) and no longer as the request pack's outcome returned (spec_lf_facts_request's OUTCOMES and spec_steps4_bring's CONVEY key on the word, features_vocab4_request on where == the pack). Feasible design: a term that redefines a request pack verb keeps the pack's sense beside its own as two senses of the verb; the frames tell them apart when a slot's kinds do not overlap (a thin frame '<actor> returns <tool>' takes agent, which overlaps the pack's 'service returns thing'; 'Frame: the member returns <tool>.' names an actor that is no service). No v_t6 for such a term; the pack's readers (OUTCOMES, CONVEY, THENS) keyed by the pack's sense, not the word; v_t15 extended to a context sense against the pack's sense it keeps, its message naming the term, the pack and the pack's frame and saying to give the term a frame whose kinds tell it apart (an actor in its subject) or another verb. Fix also grammar/rules.md's v_t6 label (it is not 'two terms are written the same' only) by the catalogue entry, not by hand.
