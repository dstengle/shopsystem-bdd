# model logic finds the clash of a negated restriction with a value it rules in

## Notes

batch-32 review 1 (f1): in grammar/check.lp gap/pag, an oattr(A,X,T,V) with V != W does not entail onattr(B,Y,T,W), so 'print a stage whose status is open' and 'shall not print a stage whose status is not done' under one trigger give no L1.

## Requirements

### design-model-check

#### [g323] `model logic` finds the clash of a forbidden object whose value is not one code with an obliged object of another value
- [r323] While a requirement uses `not-relative` and a code and the requirement forbids an act and another requirement obliges the act and the requirement uses `rc-whose` and the requirement does not use the code, when the person runs `model logic`, `model` shall print `L1`.

#### [g324] `model logic` finds no clash of a forbidden object whose value is not one code with an obliged object of that value
- [r324] While a requirement uses `not-relative` and a code and the requirement forbids an act and another requirement obliges the act and the requirement uses `rc-whose` and the code, when the person runs `model logic`, `model` shall exit successfully.
