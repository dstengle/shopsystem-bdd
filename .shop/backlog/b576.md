## Requirements

### shop

narrator: the person
group: service
purpose: The bounded contexts a shop keeps, each by its id under the product of the shop.

#### [g1] A bounded context entrusted to the shop is kept
- [r1] When the person entrusts a bounded context with an id, the shop service shall keep the bounded context in the shop and complete the request.

#### [g3] A bounded context with an id outside the product of the shop is not kept
- [r3] If the person entrusts a bounded context with an id that the product id of the shop does not cover, then the shop service shall refuse the request and name the id.

#### [g4] A bounded context is not kept twice under one id
- [r4] While a bounded context that has an id is in the shop, if the person entrusts a bounded context with the id, then the shop service shall refuse the request and name the id.

#### [g5] The bounded contexts the shop keeps are listed
- [r5] When the person lists the shop, the shop service shall return every bounded context that is in the shop.

#### [g6] A shop that keeps no bounded context lists this bounded context
- [r6] While no bounded context is in the shop, when the person lists the shop, the shop service shall return this bounded context.

### shop model

```model
service shop
  operation keep(bounded context, id)  outcomes: done → the bounded context | refused: id not in the context id form, id outside the product id, id kept already
  operation list(shop)  outcomes: returned → every bounded context

object shop
  relations: holds → bounded context (many); has → product id (one)

object product id kind of text
  relations: covers → id (many)
```

- **the shop service** (proper noun) → service shop.
- **entrust** (verb, action) → operation shop.keep. The person gives a bounded context to the shop to keep under its id, beside the bounded contexts the shop keeps already. Forms: entrusts, entrusted. Frame: <actor> entrusts <bounded context>.
- **list** (verb, action) → operation shop.list. The person asks which bounded contexts a shop keeps. Forms: lists, listed. Frame: <actor> lists <shop>.
- **shop** (noun) → object shop. The unit one product's work is managed and executed in, which keeps bounded contexts, each under its id. Plural: shops. This: the shop the request is made in.
- **product id** (noun) → object product id. The id of the product a shop belongs to, the part of the id of this bounded context before its last part, as `missingmass.io/shopsystem`. Plural: product ids.
- **cover** (verb, state) → relation product id.covers. An id lies under a product id: the path of the id opens with the product id. Forms: covers, covered. Frame: <product id> covers <id>.
