# work line takes a model line or a vocabulary entry back out of an item

## Notes

Found writing the contract artifact: b42's model row 'context request holds term proposal' gave v_t10 (a term proposal is a request line, which a context request holds already) and had to be taken out of .shop/backlog/b42.md by hand (commit a1cfe2512); --remove and --reword reach only requirement lines.
An item's own model line (an element with its members, under its area's ### <area> model block) or vocabulary entry (a term) taken back out of the item, or given a new text, by command in one commit, as --remove and --reword do for its requirement lines; refused naming the model line or the term when the item holds none of it. Found by b42 (commit a1cfe2512, a model row taken out by hand). The person's words in quote-68.

## Requirements

### drafting

#### [g35] A model line removed from an item leaves it
- [r35] When the person removes a model line from an item, the drafting service shall not keep the model line in the item.

#### [g36] Removing a model line that an item does not hold is refused
- [r36] If the person removes a model line from an item that does not hold the model line, then the drafting service shall refuse the request and name the model line.

#### [g37] Rewording a model line of an item keeps the new model line
- [r37] When the person rewords a model line in an item, the drafting service shall keep a different model line in the item.

#### [g38] Rewording a model line that an item does not hold is refused
- [r38] If the person rewords a model line in an item that does not hold the model line, then the drafting service shall refuse the request and name the model line.

### tracking model

```model
service drafting
  operation remove model line(model line, item)  outcomes: done | refused: model line not in the item
  operation reword model line(model line, item)  outcomes: done | refused: model line not in the item
  operation remove term(term, item)  outcomes: done | refused: term not in the item
  operation reword term(term, item)  outcomes: done | refused: term not in the item
```

- **remove** (verb, action) → operation drafting.remove model line. Forms: removes, removed. Frame: <actor> removes <model line> from <item>.
- **reword** (verb, action) → operation drafting.reword model line. Forms: rewords, reworded. Frame: <actor> rewords <model line> in <item>.
- **remove** (verb, action) → operation drafting.remove term. Forms: removes, removed. Frame: <actor> removes <term> from <item>.
- **reword** (verb, action) → operation drafting.reword term. Forms: rewords, reworded. Frame: <actor> rewords <term> in <item>.
