# An upgrade rewrites a consumer's old command lines to shop's

## Notes

Split from b575 (quote-83, decision 0132). A migrate upgrade step of the release that brings shop: each line of a consumer's instructions files (the hooks of .claude/settings.json, CLAUDE.md, .shop/delivery.toml's [batch] tests and [review] checks, the pages under docs/) that runs work, spec, model, measure, migrate, tools or features by its old name rewritten to shop <name>, in the upgrade's one commit; a line that only mentions a name, not running it, left alone. Technical call: no other file is read; the step is planned on every upgrade from a release before it, as the scenario conftest step is (b423).
Rated: medium value (consumers' hooks and docs follow the rename without hand edits), low urgency (aliases cover a release), small size (one upgrade step module and its scenario, about 200-300 changed lines).

## Requirements

### upgrades

#### [g44] An upgrade rewrites an old command line of an instructions file
- [r44] While the release of this repository is before the release of the plugin and an instructions file of this repository holds an old command line, when the person upgrades this repository, the upgrades service shall change the old command line and keep the instructions file.

### upgrades model

```model
object instructions file kind of tracked file
  relations: holds → old command line (many)

object old command line kind of text
```

- **instructions file** (noun) → object instructions file. A file of a repository that runs the plugin's commands for a session or a person: the hooks of `.claude/settings.json`, `CLAUDE.md`, `.shop/delivery.toml` or a page under `docs/`. Plural: instructions files.
- **old command line** (noun) → object old command line. A line of an instructions file that runs `work`, `spec`, `model`, `measure`, `migrate`, `tools` or `features` by its old name, in place of `shop <name>`. Plural: old command lines.

### specification model

```model
object repository
  relations: has → instructions file (many)
```
