# An item that imports a pack and retires its kinds' own declarations passes the bar

## Notes

Three gaps found shaping b618 (defects batch-113 defect-1, defect-2 of b672, batch-100 defect-1 of b609): the readiness bar counts an item's imports and retirements as its lines; a term retirement a model line retirement of the same item already took out is satisfied at the lay, and work line can take a retirement back out of an item; a model object that names an imported pack's noun (text, file, repository, bounded context) is that noun's kind in the lexicon once its own entry is retired, so 'Kind of:' it, its attributes and frames naming it read.
Rated: high value, since b618 waits on it; high urgency, since it is b618's last blocker; medium size: three work line options, the lay's term retirement, the bar's count and the lexicon's pack kinds, estimated under 1000 lines, so not split.
Worlds to fail first. drafting r79-r84: work line runs with --reinstate-model, --reinstate-term and --remove-import (technical call: the options' names) on an item that holds the retirement or import (r79, r81, r83) or not (r80, r82, r84); argparse refuses them today. batches r135: readiness_world's codified spec with the domain-model fixture (as batches_handlers_restate.py builds), the ready item retiring a fixture element and the vocabulary entry that means it; today the lay refuses the term retirement and batch start returns the item shaped, so the Then reading the area's layer on the batch branch fails. ### tracking model

```model
service drafting
  operation reinstate model line(model line, item)  outcomes: done | refused: model line not retired by the item
  operation reinstate term(term, item)  outcomes: done | refused: term not retired by the item
  operation remove import(pack, item)  outcomes: done | refused: pack not imported by the item
```

- **reinstate** (verb, action) → operation drafting.reinstate model line. The person takes a model line's retirement back out of an item, so that its batch keeps the element. Forms: reinstates, reinstated. Frame: <actor> reinstates <model line> in <item>.
- **reinstate** (verb, action) → operation drafting.reinstate term. The person takes a term's retirement back out of an item, so that its batch keeps the entry. Forms: reinstates, reinstated. Frame: <actor> reinstates <term> in <item>.
- **remove** (verb, action) → operation drafting.remove import. The person takes a pack's import back out of an item, so that its batch does not import the pack. Forms: removes, removed. Frame: <actor> removes <pack> from <item>.

### specification model

```model
object term
  relations: spells → element (many)
```

- **spell** (verb, state) → relation term.spells. A term of an imported pack is the word of an object the domain model declares, so that the object reads as the term's kind once no vocabulary entry means the object. Forms: spells, spelled. Frame: <term> spells <element>.
