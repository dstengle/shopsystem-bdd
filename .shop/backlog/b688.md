# An item that imports a pack and retires its kinds' own declarations passes the bar

## Notes

Three gaps found shaping b618 (defects batch-113 defect-1, defect-2 of b672, batch-100 defect-1 of b609): the readiness bar counts an item's imports and retirements as its lines; a term retirement a model line retirement of the same item already took out is satisfied at the lay, and work line can take a retirement back out of an item; a model object that names an imported pack's noun (text, file, repository, bounded context) is that noun's kind in the lexicon once its own entry is retired, so 'Kind of:' it, its attributes and frames naming it read.

## Requirements

### drafting

#### [g79] A model line reinstated in an item is no longer retired
- [r79] When the person reinstates a model line in an item, the drafting service shall keep the item that does not retire the model line.

#### [g80] Reinstating a model line that the item does not retire is refused
- [r80] If the person reinstates a model line in an item that does not retire the model line, then the drafting service shall refuse the request and name the model line.

#### [g81] A term reinstated in an item is no longer retired
- [r81] When the person reinstates a term in an item, the drafting service shall keep the item that does not retire the term.

#### [g82] Reinstating a term that the item does not retire is refused
- [r82] If the person reinstates a term in an item that does not retire the term, then the drafting service shall refuse the request and name the term.

#### [g83] A pack import removed from an item is no longer imported
- [r83] When the person removes a pack from an item, the drafting service shall keep the item that does not import the pack.

#### [g84] Removing a pack that the item does not import is refused
- [r84] If the person removes a pack from an item that does not import the pack, then the drafting service shall refuse the request and name the pack.

### batches

#### [g135] A batch opened takes out a retired term whose element a retired model line already took out
- [r135] While an item is `ready` and the item meets the readiness bar and the item retires a model line that restates an element and the item retires a term that means the element, when the person opens a batch, the batches service shall keep an area that does not hold the term.

### items

#### [g68] A shaped item whose only lines are pack imports is readied
- [r68] While an item is `shaped` and the item imports a pack and the item holds no requirement and the item meets the readiness bar, when the person readies the item, the backlog service shall set the status of the item to `ready`.

#### [g69] A shaped item whose only lines are retired terms is readied
- [r69] While an item is `shaped` and the item retires a term and the item holds no requirement and the item meets the readiness bar, when the person readies the item, the backlog service shall set the status of the item to `ready`.

### tracking model

```model
service drafting
  operation reinstate model line(model line, item)  outcomes: done | refused: model line not retired by the item
  operation reinstate term(term, item)  outcomes: done | refused: term not retired by the item
  operation remove import(pack, item)  outcomes: done | refused: pack not imported by the item
```

- **reinstate** (verb, action) → operation drafting.reinstate model line. The person takes a model line's retirement back out of an item, so that its batch keeps the element. Forms: reinstates, reinstated. Frame: <actor> reinstates <model line> in <item>.
- **reinstate** (verb, action) → operation drafting.reinstate term. The person takes a term's retirement back out of an item, so that its batch keeps the entry. Forms: reinstates, reinstated. Frame: <actor> reinstates <term> in <item>.
- **remove** (verb, action) → operation drafting.remove import. The person takes a pack's import back out of an item, so that its batch does not import the pack. Forms: removes, removed. Frame: <actor> removes <pack> from <item>.

### specification model

```model
object term
  relations: spells → element (many)
```

- **spell** (verb, state) → relation term.spells. A term of an imported pack is the word of an object the domain model declares, so that the object reads as the term's kind once no vocabulary entry means the object. Forms: spells, spelled. Frame: <term> spells <element>.
