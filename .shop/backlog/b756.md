# spec explain keeps a recipient's preposition when no frame of a verb of several fits its kinds

## Notes

batch-138 review 1 observation (b751): model_explain.word returns '' when no frame's slot kinds fit and the verb has several frames, dropping the preposition even when all frames share it. Fix: fall back to the shared preposition, else the first frame's word. Source: batch-138 review 1.
The fix: model_explain's word (scripts/model_explain.py) falls back, when no frame of a verb of several frames fits the kinds of the request's object and recipient, to the preposition all its frames share, else to the first frame's, never ''. One line beside consistency#r46 (frames of different prepositions): frames that share a preposition. World that fails first: design_model_check_worlds' world of r46 (a response's request with an oblique role) with the verb given two frames that both put the same preposition before the recipient and whose object and recipient kinds neither frame takes (kinds of another branch of the kind tree): today word returns '' and the consequence spec explain prints has no preposition, so the Then that it returns the consequence with it fails. Modules: scripts/model_explain.py, tests/scenarios/design_model_check_worlds*.py (a row beside r46's world), tests/scripts/test_model_explain*.py. Source: batch-138 review 1 (b751).
