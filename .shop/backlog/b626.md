# A reply trigger names the request's object

## Notes

grammar 4 cannot tie a reply to the object it is about ('If the notebook service refuses the request ... the invitation' is refused for lack of an antecedent), so a compensation or a lifecycle waiting on a reply cannot be written. found by the notes product worked example (2026-11-25).

## Requirements

### parsing

#### [g25] A trigger on a reply to a request about its object is parsed
- [r25] When the person parses a requirement that uses `reply-trigger`, the language service shall complete the request.

#### [g26] The logical form keeps the request a reply is on
- [r26] When the person parses a requirement that uses `reply-trigger` with the logical form, the language service shall return a logical form that holds a replied request.

### checking

#### [g125] A port outcome a reply trigger is on is handled
- [r125] While a driven port holds an operation that has an operation outcome and a core line that uses `reply-trigger` handles the operation outcome, when the person validates this specification, the specification service shall complete the request.

### consistency

#### [g44] A requirement whose trigger is a reply is translated
- [r44] While a requirement of a capability uses `reply-trigger`, when the person examines this specification with the capability, the specification service shall return a translation of the requirement.

### scenarios

#### [g44] generation introduces the thing a reply trigger's request is on
- [r44] While a requirement of a requirement group of a capability uses `reply-trigger`, when the person generates the feature of the capability, the scenarios service shall not keep a step that mentions an instance that no given step and no when step introduce.

### specification model

```model
object replied request kind of text

object logical form
  relations: holds → replied request (many)
```

- **replied request** (noun) → object replied request. The request that a reply trigger is on, said "the request to <operation verb> <np>" after complete, return, refuse or fail, as in "When the registry service completes the request to publish the design-decision", which a requirement that uses `reply-trigger` says and its logical form keeps as `request(r, O, object: x)` beside the reply's act on r. Plural: replied requests.
