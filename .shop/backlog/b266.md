# Object comparisons: one thing's value compared with another's, and a thing said to be the same as or another than one named before

## Notes

Reach: the comparison of two things' values ('the publication time of x is after the publication time of y', equal, before) in the grammar, the logical form, model logic's check and spec_steps4's Givens (each thing given a value that meets it); identity of a response's thing with a trigger's ('the video list it requested', R2's 'the K' in a response) shown in a construct and a Gherkin example. Retires known limit #6 and lets migration-tools r77-r80 compare the repository's release with the plugin's.

## Requirements

### design-model-check

- **comparison** (noun): one thing's value of an attribute said against another thing's value of the attribute, as "the release of x is after the release of y" or "is the same as", in the precondition of a requirement. Kind of: thing.
- **contradict** (verb, state): no values of two things meet both of two comparisons of the same two things' values of one attribute. Forms: contradicts, contradicted. Frame: comparison contradicts comparison.
