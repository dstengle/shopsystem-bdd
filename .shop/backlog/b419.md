# A fresh context's tests run with plain pytest without an unknown-mark warning for each @g and @r tag

## Notes

UX trial 2 (2026-11-20, 0.40.0): in the checklists context, '.venv/bin/python -m pytest -q tests' passes 11 scenarios with 22 PytestUnknownMarkWarning (pytest.mark.g1 ... r11); '-p work_items', which registers them, fails with 'No module named work_items' unless PYTHONPATH names the plugin's scripts, as the session and the batch set it. getting-started shows a clean '4 passed'. The scaffold's tests/scenarios/conftest.py (migrate init) could register the marks, or the docs give the command a person runs.
