# Entailment follows a request only to the lines of the same requester

## Notes

From b545's shaping: no line states that a premise fired by a response's request must be a line whose trigger is that request by the same requester; it was left to the implementation. A requester of another kind firing a governing line would make a false L8 premise. Needs the specification model to name a request's requester before a line can say it (decision 0118). Before b551.
