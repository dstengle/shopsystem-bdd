# An item's model lines change an existing operation: a parameter added, renamed or removed, an outcome or a reason added

## Notes

The lay of an item's model block (scripts/backlog_model.py merged/lay) only appends member lines to an element the area declares: an operation is one line of its service, its parameters, outcomes and reasons inline, so an item cannot add, rename or remove a parameter or add an outcome or a reason of an operation the model declares already; it would be appended as a second operation of the same name (v_m8). A model line that restates an operation (same service and name) is laid in place of the operation's line, and put back on unlay (park, abandon, the readiness bar's copy). From the missing-command research, the person's words in quote-68.

## Requirements

### drafting

#### [g27] A model line that restates an operation is kept in the item
- [r27] While a model line restates an operation, when the person declares the model line in an item, the drafting service shall keep the model line in the item.

### batches

#### [g77] A batch opened lays a model line in place of the operation it restates
- [r77] While an item is `ready` and the item meets the readiness bar and the item holds a model line that restates an operation, when the person opens a batch, the batches service shall keep the model line in the domain model and keep a domain model that holds exactly one model line that restates the operation.

#### [g78] An item parked takes its restating model line out of the domain model
- [r78] While an item in a batch is `in-batch` and the item holds a model line that restates an operation and the domain model holds the model line, when a session parks the item, the batches service shall keep a domain model that does not hold the model line.

- **restate** (verb, state) → relation model line.restates. A model line declares an operation that a service of the domain model declares already, under the same service and name, with the parameters, outcomes and reasons the operation is to have in place of its own. Forms: restates, restated. Frame: <model line> restates <operation>.
- **domain model** (noun) → object domain model. The files `spec/model/<area>.md` of this bounded context, each declaring the objects, services and operations of one area. This: the domain model of this bounded context. Plural: domain models.
