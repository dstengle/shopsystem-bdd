# A response's request without parameters is keyed as a request

## Notes

batch-81 review 1 f2 (observation): since b545 a response's request with parameters is a resp of the key req(O,Ps), but a response act of the same operation verb with no parameters keeps its plain event, so 'shall publish the design-decision with the summary s1' beside 'shall not publish the design-decision' on one trigger gives no L1 (it did before b545). Key a response act of an operation verb as a request even with no parameters, req(O,()), checked against the parameterised keys under the same covering rule as the chain's (f1).
