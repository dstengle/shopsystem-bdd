# Scenario steps reuse the requirement's parsed noun phrases and frames, not rebuild them from the logical form

## Notes

spec_steps4 and its siblings (about 1,300 lines) rebuild each step's tree from the logical form: frame() re-chooses the frame by kinds, and noun phrases are reassembled from referents. Keeping the subtrees of the requirement's own GF parse, with only the determiner and the instance name swapped in, may shrink that code and remove a class of wrong frame choices. Moving the rewriting into GF instead is ruled out: see .shop/records/2026-11-18-features-as-gf-concrete.md (pgf's compute segfaults, def rules fail silently on a missing case, carry no state, and would have to be generated per context).
