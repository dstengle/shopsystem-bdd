# An order after 'every K' of any act, not only print

## Notes

From the feed product's session on 0.35.0 (feedback relayed by the person, 2026-11-16), item 5: 'return every video from the channel, ordered by ...' is refused; order-by-every exists only after print.
Found shaping b298 (2026-11-16): the cause is likely a frame whose object names a kind other than `thing`, not the act. With `Frame: agent returns file to agent`, "`work` shall return every file, ordered by version, in ascending order to the person" gives `does not parse at ordered (token 13 of 23)`; grammar 4 seems to make `<T>_<K>_Every` only for a `thing` slot. b298 fixes the same cause for `order-by`'s scenario (spec_lf_ordered.said).
Merged in from b312 in the 2026-11-16 triage: order-by-every after a verb whose frame names the collection's kind gets no scenario ('no step of an order of worktree there'): the steps half of the same fault.
