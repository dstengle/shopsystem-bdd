# CLAUDE.md is cut to the working rules, the module map moved to a reference page

## Notes

CLAUDE.md is 274 KB (~99k tokens), loaded into every session and every agent (batch drivers, batch-implementers, pr-reviewers, trial agents) before they do anything; nearly all of it is the module map, rows of several hundred words carrying item and requirement history. The person's words in quote-107. The fix: CLAUDE.md keeps its working rules, the size limit and a pointer; the module map moves to docs/reference/modules.md, each row cut to the module's concern (no item numbers, requirement ids or history: git and the items hold those), and the rule 'a new concern gets a new module and a row' points there. Readers of the map follow it: tests/scripts/test_revision_done.py and test_retirement.py read the map's rows from the new page; agents/batch-implementer.md, pr-reviewer.md, architecture-reviewer.md, scripts/batch_brief.py and batch_driver.py and skills/building-a-batch name the page beside CLAUDE.md, read when placing or reviewing a module. Serves directive-9 and directive-11.
