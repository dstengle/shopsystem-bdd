# An item imports a plugin pack and retires a model element or a term of the domain model

## Notes

The tooling b618 needs: work line <item> --import <pack> (a plugin pack grammar/packs/<name>.md added to spec/index.md's imports: when the batch lays the item, taken out again on the unlay; a name of no plugin pack refused), --retire-model <header> (with --into: an element spec/model/ declares, taken out of its area's model file with its members and the vocabulary entries that mean it by the lay, put back as git held it by the unlay; one the domain model does not declare refused) and --retire-term <term> (a live vocabulary entry, its word or '<word> → <element>', taken out of its layer by the lay, put back by the unlay; one no layer holds refused).
