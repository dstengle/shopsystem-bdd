# An item imports a plugin pack and retires a model element or a term of the domain model

## Notes

The tooling b618 needs: work line <item> --import <pack> (a plugin pack grammar/packs/<name>.md added to spec/index.md's imports: when the batch lays the item, taken out again on the unlay; a name of no plugin pack refused), --retire-model <header> (with --into: an element spec/model/ declares, taken out of its area's model file with its members and the vocabulary entries that mean it by the lay, put back as git held it by the unlay; one the domain model does not declare refused) and --retire-term <term> (a live vocabulary entry, its word or '<word> → <element>', taken out of its layer by the lay, put back by the unlay; one no layer holds refused). Worlds to fail before: the drafting lines run work line with the new options, which argparse refuses today; the batches lines lay an item holding the import or the retirement on readiness_world's codified spec with the domain-model fixture (an element and its entry the fixture declares, as batches_handlers_restate.py builds), and read spec/index.md and spec/model/<area>.md on the batch's branch, which keep the element and lack the import today.
Rated: high value (b618, which removes the base kinds this repository declares twice, waits on it), medium urgency, medium size (three work line options with their lay and unlay).

## Requirements

### drafting

#### [g73] A plugin pack imported into an item is kept
- [r73] When the person imports a pack into an item, the drafting service shall keep the item that imports the pack.

#### [g74] Importing a pack that does not exist is refused
- [r74] If the person imports a pack that does not exist into an item, then the drafting service shall refuse the request and name the pack.

#### [g75] A model line retired in an item is kept
- [r75] When the person retires a model line in an item, the drafting service shall keep the model line in the item.

#### [g76] Retiring a model line that the domain model does not hold is refused
- [r76] If the person retires a model line that the domain model does not hold in an item, then the drafting service shall refuse the request and name the model line.

#### [g77] A term retired in an item is kept
- [r77] When the person retires a term in an item, the drafting service shall keep the term in the item.

#### [g78] Retiring a term that no area holds is refused
- [r78] If the person retires a term that no area holds in an item, then the drafting service shall refuse the request and name the term.

### batches

#### [g132] A batch opened imports each pack its items import
- [r132] While an item is `ready` and the item meets the readiness bar and the item imports a pack, when the person opens a batch, the batches service shall keep the pack that this bounded context imports.

#### [g133] A batch opened takes each retired model line out of the domain model
- [r133] While an item is `ready` and the item meets the readiness bar and the item retires a model line, when the person opens a batch, the batches service shall keep the domain model that does not hold the model line.

#### [g134] A batch opened takes each retired term out of its area
- [r134] While an item is `ready` and the item meets the readiness bar and the item retires a term, when the person opens a batch, the batches service shall keep no area that holds the term.

### tracking model

```model
service drafting
  operation import pack(pack, item)  outcomes: done | refused: no such pack
  operation retire model line(model line, item)  outcomes: done | refused: model line not in the domain model
  operation retire term(term, item)  outcomes: done | refused: term not in the vocabulary

object item
  relations: imports → pack (many); retires → model line | term (many)
```

- **import** (verb, action) → operation drafting.import pack. Forms: imports, imported. Frame: <actor> imports <pack> into <item>.
- **retire** (verb, action) → operation drafting.retire model line. Forms: retires, retired. Frame: <actor> retires <model line> in <item>.
- **retire** (verb, action) → operation drafting.retire term. Forms: retires, retired. Frame: <actor> retires <term> in <item>.
- **import** (verb, state) → relation item.imports. An item names a plugin pack that its batch adds to the imports of this bounded context's index. Forms: imports, imported. Frame: <item> imports <pack>.
- **retire** (verb, state) → relation item.retires. An item names an element the domain model declares, or a vocabulary entry, that its batch takes out of its area's model file or its layer, an element with the entries that mean it. Forms: retires, retired. Frame: <item> retires <model line>. Frame: <item> retires <term>.
