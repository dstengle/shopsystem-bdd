# A lifecycle transition no operation of its owner performs is a violation

## Notes

a rule naming each lifecycle transition that no operation of the object's own service performs (b578 fixed item's four; the rule keeps it fixed). Part of the disentangling of this repository into hosted contexts (decisions 0129-0133).
Decisions 0129-0133, 0133 (tracking owns the item's lifecycle, execution changes it through tracking's operations; b578 fixed item's four transitions, this rule keeps it so). Technical calls: a new model.lp rule v_m9, severity error, beside w_m5: a lifecycle transition of an object is performed when a line whose trigger requests an operation of a service of the area declaring the object sets the object's attribute along that transition (sets/5 with requester/3); a transition only lines of other areas' operations set, or none, is v_m9 naming the object, attribute and transition (w_m5 keeps saying the one no line causes). New facts: each operation's and each object's area. If the built rule finds a violation in this repository's spec, the batch parks the item naming the transitions, as their lines are another item's.
