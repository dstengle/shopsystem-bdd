# A bounded context obtains an upstream's contract and keeps it

## Notes

Split from b348 "A bounded context asks another for its context: its glossary, capabilities and lines, without a request for new behaviour": checking#r81, checking#r82.

## Requirements

### checking

#### [g81] A contract obtained from an upstream is kept
- [r81] When the person obtains a contract from a bounded context, the specification service shall keep the contract and keep no context request.

#### [g82] A contract is not obtained from a bounded context that has no contract
- [r82] If the person obtains a contract from a bounded context that has no contract, then the specification service shall refuse the request and name the bounded context.

### specification model

```model
object bounded context
  relations: has → contract (many)

service specification
  operation obtain(contract, bounded context, version) by the person
    outcomes: done → the contract | refused: bounded context with no contract
```
