## Requirements

### parsing

#### [g23] Two terms of one element are one referent of the logical form
- [r23] While a term means an element and a requirement uses the term and another term means the element and the requirement uses the term, when the person parses the requirement with the logical form, the language service shall return a logical form that holds at most one referent of the element.

### consistency

#### [g35] Lines on two terms of one element clash as lines on one thing
- [r35] While a term means an element and a requirement that uses the term obliges an act and another term means the element and another requirement that uses the term forbids the act, when the person examines this specification, the specification service shall return `L1`.

### specification model

```model
object element
  relations: has → referent (many)

object term
  relations: means → element (one)

object logical form
  relations: holds → referent (many)
```

- **element** (noun) → object element. One thing the domain model declares, an object, an attribute, a value, a relation, a service, an operation, an event or an actor, which a vocabulary entry names after its arrow. Plural: elements.
- **mean** (verb, state) → relation term.means. A vocabulary entry names one element of the domain model, so that entries of different layers that name one element are one referent of a line. Forms: means, meant. Frame: <term> means <element>.
