### the session, 2026-11-10T15:56:33.921000+00:00, 676bd6cf-baea-467f-a93f-5922ada6a722

````text
The **construct catalogue** would be a generated reference listing every sentence structure the grammar has, each under a short code. It works like the rule catalogue you approved (`grammar/rules.md`), where lines say "a term that violates `v_t11`". Lines about the language name a construct by its code, rather than inventing an adjective for it.

**What an entry would look like** (generated from the grammar itself, so it never drifts):

```
rc-object: relative clause with an object gap
  form:     <noun> that <subject> <verb>
  example:  a channel that a viewer subscribes to
  reading:  channel(c) ∧ subscribes(v, c)
  in:       While, When, If, responses
```

Each entry's example is parsed and checked against its reading when the catalogue is generated, so the catalogue doubles as part of the corpus.

**Lines today versus with the catalogue** (real lines from the audit):

| Today (coined word, with the definition you'd have to look up) | With the catalogue |
|---|---|
| "When the person runs `model parse` on a requirement that is **relative**, `model` shall exit successfully." (*relative*: a requirement with a noun followed by "that", a subject and a verb …) | "When the person runs `model parse` on a requirement that uses `rc-object`, `model` shall exit successfully." |
| "When the person runs `features generate` on a capability that is **refraining**, …" (*refraining*: a requirement whose response is a negated verb whose object has no antecedent) | "When the person runs `features generate` on a capability with a requirement that uses `not-response`, …" |
| "… a requirement that is **oblique** …" (a verb whose frame has a role behind a preposition other than "to") | "… a requirement that uses `oblique-role` …" |
| "… a term that is **frameless** …" | stays as it is: that's a *rule*, so it's already "a term that violates `v_t11`" |

The meaning moves out of an invented word into a named, generated, tested artifact, which is the same move as your comment schema.
````
