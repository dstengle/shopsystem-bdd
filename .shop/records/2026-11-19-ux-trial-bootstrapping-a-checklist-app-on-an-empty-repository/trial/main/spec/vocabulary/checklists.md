# The words of checklists

## Terms

- **the checklists service** (proper noun) → service checklists. What answers the person's requests about checklists.
- **checklist** (noun) → object checklist. A named list of items the person keeps.
- **item** (noun) → object item. One thing to do on a checklist.
- **title** (attribute) → attribute checklist.title. What the person calls a checklist.
- **text** (attribute) → attribute item.text. What an item says.
- **status** (attribute) → attribute item.status. Whether an item is open or done.
- **open** (adjective) → value item.status open.
- **done** (adjective) → value item.status done.
- **create** (verb, action) → operation checklists.create. Forms: creates, created. Frame: <actor> creates <checklist>.
- **add** (verb, action) → operation checklists.add. Forms: adds, added. Frame: <actor> adds <item> to <checklist>.
- **check** (verb, action) → operation checklists.check. Forms: checks, checked. Frame: <actor> checks <item>. Redefines: request.
- **list** (verb, action) → operation checklists.list. Forms: lists, listed. Frame: <actor> lists <checklist>.
