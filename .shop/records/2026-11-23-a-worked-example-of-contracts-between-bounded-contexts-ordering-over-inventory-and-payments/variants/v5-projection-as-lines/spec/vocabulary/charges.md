# The words of the charges port

## Terms

- **the charges service** (proper noun) → service charges. What secures and collects ordering's charges; payments, behind the port.
- **charge** (noun) → object charge. Money ordering asks a shopper's card for, for one order.
- **amount** (attribute) → attribute charge.amount. How much the charge is for.
- **state** (attribute) → attribute charge.state. What payments last said of a collected charge.
- **settled** (adjective) → value charge.state settled.
- **bounced** (adjective) → value charge.state bounced.
- **secure** (verb, action) → operation charges.secure. Forms: secures, secured. Frame: <actor> secures <charge> for <order>.
- **cancel** (verb, action) → operation charges.cancel. Forms: cancels, cancelled. Frame: <actor> cancels <charge>.
- **collect** (verb, action) → operation charges.collect. Forms: collects, collected. Frame: <actor> collects <charge>.
