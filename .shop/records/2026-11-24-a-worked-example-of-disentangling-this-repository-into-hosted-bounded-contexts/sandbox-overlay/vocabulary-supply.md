# The words of supply

## Terms

- **the work supply** (proper noun) → service supply. Where execution's assignments come from and go back to.
- **claim** (verb, action) → operation supply.claim. Forms: claims, claimed. Frame: <actor> claims <assignment>.
- **fulfil** (verb, action) → operation supply.fulfil. Forms: fulfils, fulfilled. Frame: <actor> fulfils <assignment>.
- **relinquish** (verb, action) → operation supply.relinquish. Forms: relinquishes, relinquished. Frame: <actor> relinquishes <assignment>.
- **defer** (verb, action) → operation supply.suspend. Forms: defers, deferred. Frame: <actor> defers <assignment>.
- **claim** (noun) → object claim. The batches service's request that the work supply let a batch hold an assignment.
