## Where 0055's rewording forced a meaning choice (listed, not decided)
1. supervision r9/r32: the old r9 covered every stop. The new pair covers only "all green or withdrawn" and "one
   awaiting-ruling". A stop with neither (e.g. a work-item left `drafted`/`planned`/`done` that cannot move, none
   awaiting a ruling; Implementation's exit 1 "otherwise") has no Behaviour line saying whether it exits with an
   error or what it prints.
2. design-model-check r11: "leaving the exit code as the other findings set it" -> "with no effect on whether it
   exits successfully"; r33: "with the same exit code" -> "exiting as it would without `--json`". Equal in
   intent, but the wording no longer pins the code itself (1 vs 2) as the same.
3. design-model-check r12 (no clingo): "exit 2" -> "exit with an error"; the distinction from a found problem
   (exit 1) now lives only in Implementation. The formulating-features skill still tells the round to tell a
   clingo-missing exit 2 from other runs by its code and message.
4. Empty or negative results now worded as errors: analysis-tools r11 (no test executed the target), r16 (a
   linter found something), r3 (a tool missing on probe); feature-file-tools r7 (`features list` matched nothing);
   design-model-check r17 (`model why` with no proposal). These read as "exit with an error", though they are
   findings, not failures.
5. analysis-tools r8 `tools map` "exit successfully whether or not the tests passed": while a map that makes no
   map is a refusal under r49 (Implementation) — consistent, but r8 alone reads as always successful.
6. Glossary **check** ("whose exit code 0 shows its work complete") and docs/capability-format.md's tool
   description ("exits 0", "exits 2") still name codes; they are not Behaviour lines, left as they are.
7. spec-migration r2 now also shows a scenario that formulates more than one line at the gate (needed for r11 to
   be satisfiable under 0054; a 0054 choice, not 0055).
8. design-model-check r107 counts a feature-level `@r<n>` with a scenario's own as "more than one" (0054 choice).
