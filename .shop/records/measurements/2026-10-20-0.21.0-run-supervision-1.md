2. The question lives in the work-item file, under `## Questions` (one bullet each, appended after the move and committed with it). r9 prints those lines for awaiting-ruling items. Decision 0039 puts rulings under `## Rulings`, but no place for the questions is fixed.

4. r10's "change nothing" is read as checking, before any worker starts, every work-item of the initiative with move's own checks (exists, has a status, agrees with log.jsonl). So a disagreement refuses the whole run up front, rather than after a worker has run.
5. No `.shop/delivery.toml`, or no `[tests]` key, means the Implementation note's commands (`python3 -m pytest -q --work-item {work_item}`, `python3 -m pytest -q`). `{work_item}` in the toml is replaced by the name.

7. r6 puts back changed and deleted files. A file the worker *adds* under .shop/work/ outside its run dir is left in place, uncommitted, because no scenario covers it.
8. The brief's "files to read" are the work-item file, `spec/capabilities/<under>.md` and the work-item's earlier run directories.

Per `claude --help`, tool access is limited to the working directory unless `--add-dir <directories...>` ("Additional directories to allow tool access to") is given.
