# The words of notes-cli

## Terms

- **the notes service** (proper noun) → service notes. What answers the person's and the clients' requests about notes.
- **note** (noun) → object note. One short text the person keeps, with a title.
- **tag** (noun) → object tag. A word the person files a note under.
- **reader** (noun) → object reader. Someone other than the person whom a note is open to.
- **allowance** (noun) → object allowance. How many notes the person may keep.
- **bundle** (noun) → object bundle. Every kept note taken together, as one thing to hand over or take in.
- **title** (attribute) → attribute note.title. The one line that names a note.
- **spelling** (attribute) → attribute tag.spelling. The word a tag is written as.
- **size** (attribute) → attribute allowance.size. The number of notes an allowance permits.
- **status** (attribute) → attribute note.status. Whether a note is kept or removed.
- **kept** (adjective) → value note.status kept.
- **removed** (adjective) → value note.status removed.
- **add** (verb, action) → operation notes.add. Forms: adds, added. Frame: <actor> adds <note>.
- **list** (verb, action) → operation notes.list. Forms: lists, listed. Frame: <actor> lists the notes.
- **remove** (verb, action) → operation notes.remove. Forms: removes, removed. Frame: <actor> removes <note>.
- **rename** (verb, action) → operation notes.rename. Forms: renames, renamed. Frame: <actor> renames <tag>.
- **open** (verb, action) → operation notes.open. Forms: opens, opened. Frame: <actor> opens <note> to <reader>.
- **close** (verb, action) → operation notes.close. Forms: closes, closed. Frame: <actor> closes <note> to <reader>.
- **enlarge** (verb, action) → operation notes.enlarge. Forms: enlarges, enlarged. Frame: <actor> enlarges <allowance>.
- **reduce** (verb, action) → operation notes.reduce. Forms: reduces, reduced. Frame: <actor> reduces <allowance>.
- **export** (verb, action) → operation notes.export. Forms: exports, exported. Frame: <actor> exports the notes.
- **import** (verb, action) → operation notes.import. Forms: imports, imported. Frame: <actor> imports <bundle>.
