# The words of accounts

## Terms

- **the accounts service** (proper noun) → service accounts. What answers the person's requests about plans.
- **plan** (noun) → object plan. What the product offers the person: an allowance of notes for a price.
- **subscription** (noun) → object subscription. The person's taking of one plan.
- **status** (attribute) → attribute subscription.status. Where a subscription has got to.
- **requested** (adjective) → value subscription.status requested.
- **charged** (adjective) → value subscription.status charged.
- **active** (adjective) → value subscription.status active.
- **refunded** (adjective) → value subscription.status refunded.
- **subscribe** (verb, action) → operation accounts.subscribe. Forms: subscribes, subscribed. Frame: <actor> subscribes to <plan>.
