# The words of backup

## Terms

- **the backup service** (proper noun) → service backups. What answers the person's requests about snapshots.
- **snapshot** (noun) → object snapshot. The person's kept notes at one moment, as one thing to store.
- **status** (attribute) → attribute snapshot.status. Where a snapshot has got to.
- **taken** (adjective) → value snapshot.status taken.
- **stored** (adjective) → value snapshot.status stored.
- **lost** (adjective) → value snapshot.status lost.
- **save** (verb, action) → operation backups.save. Forms: saves, saved. Frame: <actor> saves the notes.
- **restore** (verb, action) → operation backups.restore. Forms: restores, restored. Frame: <actor> restores <snapshot>.
