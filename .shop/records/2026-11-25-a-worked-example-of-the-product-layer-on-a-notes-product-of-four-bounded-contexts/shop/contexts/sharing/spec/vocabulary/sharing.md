# The words of sharing

## Terms

- **the sharing service** (proper noun) → service sharing. What answers the owner's and the colleague's requests about invitations.
- **invitation** (noun) → object invitation. An owner's offer to a colleague to read one note.
- **address** (attribute) → attribute invitation.address. Where the colleague is reached.
- **status** (attribute) → attribute invitation.status. How far an invitation has got.
- **sent** (adjective) → value invitation.status sent.
- **accepted** (adjective) → value invitation.status accepted.
- **declined** (adjective) → value invitation.status declined.
- **withdrawn** (adjective) → value invitation.status withdrawn.
- **share** (verb, action) → operation sharing.share. Forms: shares, shared. Frame: <actor> shares <note>.
- **accept** (verb, action) → operation sharing.accept. Forms: accepts, accepted. Frame: <actor> accepts <invitation>.
- **decline** (verb, action) → operation sharing.decline. Forms: declines, declined. Frame: <actor> declines <invitation>.
- **withdraw** (verb, action) → operation sharing.withdraw. Forms: withdraws, withdrew, withdrawn. Frame: <actor> withdraws <invitation>.
