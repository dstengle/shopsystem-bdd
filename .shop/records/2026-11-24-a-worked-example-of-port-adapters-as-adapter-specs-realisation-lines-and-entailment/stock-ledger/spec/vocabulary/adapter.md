# The adapter's own words

## Terms

- **entry** (noun) → object entry. The adapter's stored record of an order's reservation. Plural: entries.
- **progress** (attribute) → attribute entry.progress. What the adapter has done at the ledger for the entry.
- **decremented** (adjective) → value entry.progress decremented.
- **taken** (adjective) → value entry.progress taken.
- **returned** (adjective) → value entry.progress returned.
- **deadline** (noun) → object deadline. The moment an entry not taken lapses: an adapter setting (adr/0002).
