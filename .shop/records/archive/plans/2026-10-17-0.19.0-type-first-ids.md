- [ ] **Step 2:** Implement. Context: index `id` must match `bounded-context/(<path>)` with `<path>` three
  plain-name segments (domain segment may contain dots); else a file problem and no context. Resolver:

```python
KINDS = {...}  # the Global Constraints' kinds
NAME = r"[a-z0-9]+(?:-[a-z0-9]+)*"

def qualify(self, ref, kind=None):
    """<kind>/<path>/<name> as is; <kind>/<name> in this context; <name> where the field fixes the kind."""
    ref = str(ref).strip()
    if not self.path:
        return ref
    head, _, rest = ref.partition("/")
    if head in KINDS:
        if rest.startswith(self.path + "/") or (head == "bounded-context" and rest == self.path):
            return ref
        if re.fullmatch(NAME, rest):
            return f"{head}/{self.path}/{rest}"
        return ref                       # another context's full id, or malformed: resolved or reported by want()
    if kind and re.fullmatch(NAME, ref):
        return f"{kind}/{self.path}/{ref}"
    return ref
```

  Use `qualify(x, "capability")` for argues/under/depends_on and the capability part of requirement refs,
  `qualify(x, "design-decision")` for rests_on/supersedes and ledger headings, `qualify(x, "initiative")`
  is NOT implied for part_of (part_of may name an initiative or a part: require `<kind>/<name>`),
  `qualify(x)` for about/source/blocked_by/for. A frontmatter `id` must equal `qualify(id)` and start with
  `<its kind>/<path>/`; else a file problem. A capability's expected id is `capability/<path>/<file stem>`.
  Drop the 0.19.0 context-name branch. Update CONTRACT text. Run; green.
