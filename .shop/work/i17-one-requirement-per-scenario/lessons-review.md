# Review: code no line asks for

The person approved (2026-10-22) the first lesson of 0.22.0's blind formulation round: behaviour reaches code
only through a line, and a review treats code no line asks for as an Important finding.

- r29, a row of the table of what a work-item or branch review finds: code whose observable behaviour no
  Behaviour line asks for is graded Important.
- r30: such a finding is triaged fix now, its line written first or the code removed, in a re-review too, over
  r8 and r12 (lesson 2: the line says which wins). Without it, r12 would triage most such code as an
  observation and r8 would in a re-review, so behaviour a fix work-item added would reach the code unasked.
