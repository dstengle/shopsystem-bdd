# The request context of the construct catalogue

The words `model constructs` parses an example of the construct catalogue (`grammar/constructs.md`) in when its
construct is a request's (the domain contract design, §5.1): a domain model (`spec/model/`) whose service has an
operation with parameters, its vocabulary (`spec/vocabulary/`) and the domain-request pack. It is part of the
acceptance corpus, not a spec of this repository.
