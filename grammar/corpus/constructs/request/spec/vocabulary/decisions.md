# The words of decisions

## Terms

- **design-decision** (noun) → object design-decision. A decision kept with its tier. Plural: design-decisions.
- **tier** (attribute) → attribute design-decision.tier.
- **supersede** (verb, state) → relation design-decision.supersedes. Forms: supersedes, superseded. Frame: <from> supersedes <to>.
- **enter** (verb, action) → operation decisions.enter. Forms: enters, entered. Frame: <actor> enters <design-decision>.
- **the decisions service** (proper noun) → service decisions.
