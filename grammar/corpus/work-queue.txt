# work-queue: sentences that parse with exactly one tree in the fixture glossary's grammar.
When the person runs `work add`, `work` shall write a work-item that is `drafted`.
While a capability-proposal is not closed, `work` shall not set the status of an initiative to `done`.
Where `--json` is given, `work show` shall print one JSON object.
If a command is refused, then it shall exit with an error naming the reason and change nothing.
When the person runs `work answer` on a work-item that is `awaiting-answer`, `work` shall set its status to `ready`.
When the person runs `work start` on an initiative that is `proposed`, `work` shall set its status to `started`.
When the person runs `work abandon` on an initiative that is `started`, `work` shall set its status to `abandoned`.
When the person runs `work list`, `work` shall print every work-item whose status is not `green` or `withdrawn`.
When the person runs `work withdraw` on a work-item, `work` shall commit the transition and push the commit.
While an initiative is complete, `work` shall set its status to `done`.
