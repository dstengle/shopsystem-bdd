# 0.20.0 Ubiquitous language Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A bounded context's terms become standing glossary entries checked by `model check`, a new
`checking-spec-consistency` skill reports and walks through consistency fixes, `model` finds clingo behind a
virtualenv, and `features` takes `--file`; release 0.20.0 (merge, tag).

**Architecture:** Glossary entries are data: `model facts` reads `spec/index.md`'s Glossary bullets into
`term`, `avoid` and `mentions` facts; model.lp's generic `v_t1`–`v_t3` judge them. Meaning is judged by a
blind `spec-checker` agent the skill dispatches. One workflow change (the skill and the glossary); the two
script fixes ride along.

**Tech Stack:** Python 3 stdlib, clingo, unittest, Markdown skills/agents, headless `claude -p` fixture runs.

**Spec:** `docs/superpowers/specs/2026-10-17-type-first-ids-and-ubiquitous-language-design.md`, Part 2.

## Global Constraints

- Branch `0.20.0-ubiquitous-language`, cut from `main` after v0.19.0 is tagged. Push with
  `agent-vault run -- git push origin <ref>`.
- Ids are type-first (0.19.0): a term is `term/<context path>/<term>`, the term lowercased with spaces as
  hyphens; short form `term/<name>`.
- Glossary bullet form exactly: `- **<term>**: <one-sentence definition>. Not: <word>, <word>.` (`Not:` optional).
- Facts: `node(T,"term")`, `term_of(T,Ctx)`, `avoid(T,Word)`, `mentions(X,Word)` (X a requirement or a
  scenario; whole word, case-insensitive, plural "s" allowed; only for words that are terms or avoided words).
- Constraints: `v_t1(X,W,T)`, `v_t2(T)`, `v_t3(W)` as the spec states, in model.lp with FIX/extension notes
  against grammar.md.
- The skill is on demand only. `spec-checker`: tools Read, Glob, Grep, Write; reads only `spec/` and
  `features/`; writes only under the drafts path; model sonnet.
- Scripts stdlib only (clingo for `check`). Never hand-edit `spec/decisions.md`. Trailer:
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- After every task: suite OK; `model check` 0 unresolved, 0 file problems, violations only v_s3 for workflow
  capabilities (and the new capability's lines).

## Review Focus

1. A term that is a substring of another word ("store" in "restore"): whole-word matching only.
2. A glossary bullet with a period inside the definition ("e.g. a"): the `Not:` split is on `. Not:` only.
3. A term defined in the glossary and also appearing in its own `Not:` list, or in another term's: `v_t3`.
4. The interpreter search re-running forever: the environment flag stops a second re-run.
5. `--file` given a path outside `--dir`, or a file not holding the title: refused, nothing changed.
