# Module map

Each module of the plugin's `scripts/` and each test helper of `tests/` with the one concern it holds. Read it when
placing a new module or reviewing where a change belongs: a new concern gets a new module and a row here. A row says
what the module is for; the items, requirements and git history say how it came to be.
