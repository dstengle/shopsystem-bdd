# Checklists

## Purpose
The person keeps notes in checklists and reads them back: one checklist, every checklist, a note's characters and
its length.

## Behaviour

### [g1] A checklist listed returns its notes
- [r1] When the person lists a checklist, the checklists service shall return every note in the checklist.

### [g2] The checklists listed are returned
- [r2] When the person lists the checklists, the checklists service shall return every checklist.

### [g3] A note's characters listed are returned
- [r3] When the person lists the characters of a note, the checklists service shall return every character of the note.

### [g4] A note's length shown returns the note
- [r4] When the person shows the length of a note, the checklists service shall return the note.

### [g5] A note shown is returned
- [r5] When the person shows a note, the checklists service shall return the note.
