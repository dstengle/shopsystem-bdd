# The words of checklists

## Terms

- **the checklists service** (proper noun) → service checklists. What answers the person's requests about checklists.
- **checklist** (noun) → object checklist. A list of notes the person keeps together.
- **note** (noun) → object note. One short text the person keeps.
- **character** (noun) → object character. One letter, digit, space or mark of a note's text.
- **title** (attribute) → attribute checklist.title. The one line that names a checklist.
- **length** (attribute) → attribute note.length. How many characters a note has.
- **list** (verb, action) → operation checklists.contents. Forms: lists, listed. Frame: <actor> lists <checklist>.
- **list** (verb, action) → operation checklists.list. Forms: lists, listed. Frame: <actor> lists the checklists.
- **list** (verb, action) → operation checklists.characters. Forms: lists, listed. Frame: <actor> lists the characters of <note>.
- **show** (verb, action) → operation checklists.length. Forms: shows, shown. Frame: <actor> shows the length of <note>.
- **show** (verb, action) → operation checklists.show. Forms: shows, shown. Frame: <actor> shows <note>.
