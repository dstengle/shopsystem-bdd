# Labels

## Purpose
The person gives items short words, labels, to group them, and reads the backlog by them.

## Behaviour

### [g1] An item shown returns its labels
- [r1] When the person shows an item, the backlog service shall return every label of the item.

### [g2] A label an item is tagged with is kept
- [r2] When the person tags an item with a label, the backlog service shall keep the label.
