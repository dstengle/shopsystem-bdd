# The words of backlog

## Terms

- **the backlog service** (proper noun) → service backlog. What answers the person's requests about items.
- **item** (noun) → object item. One file of the backlog: work this bounded context may do.
- **label** (noun) → object label. A short word the person gives an item, to group it with others.
- **title** (attribute) → attribute item.title. The one line that names an item.
- **show** (verb, action) → operation backlog.show. Forms: shows, shown. Frame: <actor> shows <item>.
- **tag** (verb, action) → operation backlog.tag. Forms: tags, tagged. Frame: <actor> tags <item>.
