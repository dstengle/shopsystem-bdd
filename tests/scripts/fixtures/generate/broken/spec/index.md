# The broken fixture

A codified context with one requirement that does not parse, for the layer 2 gate (v_p1) and the refusal of
`features generate`. It is not this repository's spec.

## Glossary

- **the person** (proper noun): the human who runs the commands.
- **`work`** (proper noun): the queue's command.
- **initiative** (noun): the delivery of one request.
- **status** (attribute of initiative): Values: `proposed`, `started`.
  Transitions: `proposed` → `started`: `work start`.
