# The words of notes

## Terms

- **note** (noun) → object note. A short text a person keeps. Plural: notes.
- **tag** (noun) → object tag. A word a note carries.
- **status** (attribute) → attribute note.status.
- **priority** (attribute) → attribute note.priority.
- **draft** (adjective) → value note.status draft.
- **active** (adjective) → value note.status active.
- **retired** (adjective) → value note.status retired.
- **low** (adjective) → value note.priority low.
- **high** (adjective) → value note.priority high.
- **carry** (verb, state) → relation note.carries. Forms: carries, carried. Frame: <from> carries <to>.
- **add** (verb, action) → operation notes.add. Forms: adds, added. Frame: <actor> adds <note>.
- **file** (verb, action) → operation notes.file. Forms: files, filed. Frame: <actor> files <note>.
- **archive** (verb, action) → operation notes.archive. Forms: archives, archived. Frame: <actor> archives <note>.
- **the notes service** (proper noun) → service notes.
